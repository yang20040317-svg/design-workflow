# taste-profiles（独特品味档案容器）

本目录是 `design-taste` 子技能（模式2本体）的**独特品味库**。每个文件是一个独立的"品味实例"，可含图片风格、动效、色彩、排版等完整组合。SKILL.md 定义使用协议，本目录只装实例。

## 如何新增一个品味实例

1. 复制下面任意一个 `.md` 作为模板。
2. 文件名用 `<id>.md`，`id` 与文件内 frontmatter 的 `id` 一致。
3. 在 `references` 字段列出**实际参考图文件名**（或私有链接），并把图片放在本目录（与 `.md` 同级）。正文必须严格写成三段式：**🟦 参考图事实 / 🟥 品味维度（仅用户原话，AI 不增补）/ 🚫 红线**。
4. 生成时对照 `references` 图片，按 `composable_with` 决定是否可与其他实例组合。
5. 无需修改 SKILL.md——容器自动识别新实例。
