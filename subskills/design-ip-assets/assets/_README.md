# assets/ ｜ 专属视觉资产容器

> 本目录装「design-ip-assets」的 5 类专属资产。每个资产一个 `.md`，字段见上级 `SKILL.md` 第二节 schema。

## 现状（附「三果团」完整示例，演示如何填）

> 本目录随技能附**一套已填好的示例资产「三果团」**（角色/符号/配色/字体/图形语言五类全齐），仅作 **schema 示范**——每个 `.md` 顶部都标了 `status: example` 与「示例」说明。它**不是强制资产**，实际使用时请整体替换为你的专属 IP：直接编辑这五个文件，或另建文件后改名覆盖。

| 资产 | 文件 | 状态 |
|---|---|---|
| 角色/吉祥物 IP | `character.md` | 示例（三果团），待你替换 |
| 固定符号母题 | `sigil.md` | 示例（三果印），待你替换 |
| 专属配色签名 | `palette.md` | 示例（三果红），待你替换 |
| 字体人格 | `typeface.md` | 示例（圆体人格），待你替换 |
| 图形语言 | `graphic-language.md` | 示例（圆润果感），待你替换 |

## 如何新增/维护资产
1. 以本目录示例为模板，按上级 `SKILL.md` 第二节 schema 填字段；有实际图放同目录 `<asset>-ref-*.png`。
2. **资产默认固定**，不随单次 brief 漂移（见上级 SKILL.md 第四节优先级）。
3. 改资产 = 改本目录文件，不动上级 SKILL.md 协议。
