# design-typographic-glyph ｜ 图形字（合字共生）专项

> 本技能是 design-workflow 主技能抽离出的**专项方法论**，专治"把具象图形寄进汉字骨架、与字共生成新视觉单元"的强记忆点设计（文创、海报、节令物产、品牌字、系列图标）。
> 本技能是 design-workflow 主技能抽离出的**专项方法论**，专治"把具象图形寄进汉字骨架、与字共生成新视觉单元"的强记忆点设计（文创、海报、节令物产、品牌字、系列图标）。

## 何时用

- 任务是**让人第一眼记住是什么字 + 是什么物**（节令物产、品类系列、海报标题、店招字）。
- 受众能接受**字识别度稍降**换**记忆点陡升**（多用作品牌/节庆/文创，非日常信息流）。
- 已有**系列化需求**：禽/水产/食材/四时物候等一组多字。

## 核心机制——以字寄形、彼此借用笔画

- **字形骨架仍要可识别**：汉字的笔画结构（左右/上下/包围/独体）是观者的识读入口；图形寄生其中，但**不能毁字的可读性**。
- **彼此借用笔画（合字，而不是配图）**：图与字共用同一组黑色笔触。失败做法是字与一个完整小图并排（即"配图"）；成功做法是它们被合并成**单一可识别单元**——既读此字，也见此物。例如鸟的喙可借字的一笔延伸；动物身躯坐中宫；植物的茎叶从撇捺长出。
- **共享笔画 ≠ 双倍笔画**：合字总笔画数应接近原字笔画数（±1–2），只把一处笔换成"既为字也为形"。

## 字体选型（合字友好）

合字要求字库**骨架粗壮、笔画可被图形借用、笔触本身有质感**——而非细瘦几何体。

- **书法体 / 北碑体**：笔画粗壮、转折可借作图形的肩/颈/喙/尾
- **颜楷 / 褚体一类**：骨架端正、笔画可拆借、识别度高
- **篆意美术字 / 民间美术字**：自带装饰性，常与图形共生

> 商用模式仍查字体授权——单字/合字整体视觉的版权属字体作者；不在"技法免费"清单内。

## 设计三轴（动手前先定）

| 轴 | 决策 | 通用取舍 |
|---|---|---|
| **形之位** | 图形主体挂在字哪个区位 | 中宫/偏上/偏下/偏角，依字结构（左右/上下/包围/独体）选 |
| **色之制** | 用几色 | 默认**墨朱制**（黑主+朱红印+白底）三色；可扩四色（加一抹点缀），绝不超 |
| **图所占** | 图形占字面积几成 | 30–60%；过小=装饰偷换主题，过大=字被吞 |

## 图字共生三型

| 共生型 | 说明 | 视觉关系 |
|---|---|---|
| **形嵌字**（动物/物形坐进字的中宫） | 图形占据中央主要笔画位，字的外框基本保留 | 图为主语义、字为外壳 |
| **笔成形**（字的某笔延展成图形） | 字的笔画本身就是图形的一部分（鸟喙=字撇、鱼尾=字捺） | 字为主语义、图作延伸 |
| **包围形**（图形补字的环境位） | 图形在字外（脚踩字下、头顶字上），字主体不动 | 字独立、图补环境 |

## 图字共生第四型——填字共生型（物品结构承载文字）

> 当主体是**真实可识别物品**（器物/动物/植物/人物/自然元素），而非单个汉字时触发。与"以字寄形"相反：**先有物品结构，再把主题文案与辅助文字填充进物品内部，最后让少量文字笔画突破边缘向外生长**。啤酒杯、鸟、树、花、鱼、房屋等具象主体适用。

### 核心视觉机制：物品形态 + 文字填充 + 文字生长

核心主体必须**首先是一个清晰、完整、高识别度的真实物品形态**（杯口/泡沫/杯身/杯底/杯把、头/喙/眼/身/翼/尾……），不要做成抽象文字图形，不要强制用巨大汉字拼成物品。

形成三层关系：

```
物品结构承载文字  →  文字丰富物品结构  →  局部文字突破物品结构
```

### 文字填充规则

- 文字不是普通排版、不是"贴字"，而是**物品内部的主要视觉构成**。
- 根据主体不同区域自动调整文字大小/方向/密度/笔画：允许大字、中字、小字、短句、单字、碎片化文字、局部笔画。
- 文字顺着物品结构自然排列；不要求大小一致、不要求全部横向、不要求全部完整。
- 文字数量随主体大小自然调整：**主体大→较多大小不同的字；主体小→减少字数**；禁止无意义重复、禁止无意义乱码填充。

### 文字与主体的融合（允许 / 禁止）

| 允许 | 禁止 |
|---|---|
| 进入主体内部 | 用完整外轮廓把文字框住 |
| 沿主体边缘排列 | 文字被装进形状容器 |
| 覆盖主体局部结构 | 明显文字蒙版效果 |
| 与主体结构重叠 | 所有文字规规矩矩待在内部 |
| 从边缘自然伸出 / 飞白 / 断裂笔锋 / 局部延伸 / 少量飞散墨点 | — |

正确效果：**主体有清晰物品形态，文字主要在内部，少量笔画突破边缘 → "文字从物品内部生长出来"**。

### 主体识别优先

视觉顺序必须是 `物品 → 文字 → 融合`，而非 `文字 → 猜测物品`。

- 第一眼必须先识别出核心主体（识别度 > 融合度 > 书法艺术感 > 装饰细节）。
- 第二眼才发现主体内部由中文书法文字组成。
- 第三眼才发现部分文字笔画已突破主体边缘。

### 不强制放大核心文案

核心文案不一定放大，不需要为强调主题制造巨大核心汉字。只有当某字天然适合形成主体结构时才放大，否则以中小型手写书法为主——整体更接近**"文字组成的物品插画"**，而非**"由大字组成的物品"**。

## 关键约束

- **共墨同色、共笔触感**：图与字主笔画**完全同墨**（默认黑/墨），共享一套飞白/笔锋质感，避免"贴纸分层感"。
- **视觉权重均衡**：图形占字面积 30–60%（字结构决定）；超出此区间即失败。
- **印章作图底闭环**：朱红小印在字右上/右下角，是合字里唯一非黑强调色——既稳定构图、也是图底关系的强对照点。
- **共享笔画仅 1–2 处**：合字总笔画数接近原字笔画数，把"一处笔"换成既为字也为形，而不是把字写两遍再贴图。

## 三个不能踩

- **不能图字互不相干**：合字=图+字合一；若图形与字笔画无共用、形色错位，就退化为"配图"——不算合字。
- **不能图毁字**：图形不可毁掉字的可识别度；若有歧义，多半是图形吃掉中宫位。
- **不能多色过载**：默认**墨朱制**——黑主色、朱红印、白底，三色；超四色就丢"墨朱"调性。

## 系列化延展（推广方法）

- 一个合字做出后，可做**一组合字**——按"语义簇"延展（禽类/水产/节气物产/四时食材…）。
- 同一组里：**几何风格、线宽、笔触质感、用色制（仍墨朱）、印章制（位+大小+篆字内容）保持一致**——这是图标"套系一致性"原则在文字上的延伸（规则详见主技能 `../modules/03-形式组织/关系.md`「图标套系一致性」段，或子技能 `design-icon-batch`）。
- 网格化排版（3×N / N×N）出来的不规则留白也是整体气质的一部分，别刻意拉齐。

## 验收与红线

- **双重可识别**：观者第一眼既读出什么字、也读出什么物——任何一项模糊都失败。
- **不影响识读时**：图形可"喧宾"，但**不可毁字**——笔画残缺须仍在可读阈值。
- **印章是完成印，不只是装饰**：朱红方/圆印既装饰也承担"此作已完成"的语义，定四角之一稳定构图；不宜多处散印。
- **品牌/作者归属**：图形字风格化强、复用度低；商用时注意单字/整体视觉的版权状态与原创署名，搬运他人作品与原图作者水印需剥去后再用。

## 与五层的衔接

- **← 第 2 层 文字/图片**：选字库走书法体/北碑体/颜楷体/篆意美术字（骨架粗壮、笔画可借用）；图形生图走 `design-icon-batch` 的「AI 生图透明背景与抠图」段，注意 AI 默认透明背景陷阱（`../references/chroma_key.py`）。
- **← 第 3 层 关系**：图字共生位置、共享笔画、视觉权重均衡走「图形字·图字共生」原则（本技能已含）。
- **→ 第 5 层 验收**：双重可识别、印章完成语义、墨朱克制 都在感觉清单兜底。

## 自检（本技能专属）

- [ ] 图与字是否**共墨同色、共笔触感**，无贴纸分层？
- [ ] 共享笔画是否仅 1–2 处、未把字写两遍？
- [ ] 图形所占面积是否在 30–60% 范围？
- [ ] 双重视觉中心是否清晰（既此字也此物）？
- [ ] 朱红印章是否仅 1 枚、置字角落而非正中？
- [ ] 观者第一眼是否既读出字、也读出物（双重可识别）？
- [ ] 【填字共生型】第一眼是否先认出物品（杯/鸟/树…），再发现内部由文字组成、少量笔画突破边缘？
- [ ] 【填字共生型】是否出现完整外轮廓框字 / 文字蒙版 / 形状容器（红线，禁止）？
