# 第5层·主观输出 / 子位置：情绪

> 所属工作流步骤：第 5 步（顺序：第一层 → 第二层 → 第三层 → 第四层 → 第五层）
> 本子位置是独立可编辑模块，可单独编写，不依赖其他子位置文件。

## 本子位置定位
- **层**：第 5 层 · 主观输出
- **子位置**：情绪（emotion）
- **一句话说明**：观者在感觉之上**被唤起的情绪状态**——喜悦 / 信任 / 紧迫 / 宁静 / 向往 / 松弛。它是体验的过程，是一条可被设计的**情绪曲线**。
- **心智模型**：感觉是"一眼的味"，情绪是"待一会儿的心情"。好的设计不只第一眼对，还会在观者停留的这几秒里**带着他走一段情绪**——从被吸引，到共情，到想要行动。情绪由第 5 层「感觉」点燃，由第 4 层「故事逻辑」的节奏铺设，由第 2/3 层的物料与形式持续供给。

## 在工作流中的位置（顺序执行 + 反推）
- **正向（验收）**：走完第 4 层后，问"整个观看过程，情绪是怎么起伏的？"——若有断点（如开头很燃但结尾泄气），说明第 4 层故事节奏或第 3 层动线没接住。
- **反向（反推 · 更关键）**：先定"希望观众经历一条怎样的情绪曲线"（如"好奇→向往→行动欲"），再反推第 4 层故事逻辑的分章、第 3 层视觉流向的起承转合、第 2 层物料的情绪色彩。
- **上一步输入**：本层「感觉」（感觉是情绪的前置触发）+ 第 4 层「故事逻辑」（情绪曲线的骨架）
- **本步要做**：明确目标情绪 + 情绪曲线，确认每个情绪节点由哪层手段支撑
- **输出给**：本层后续子位置（心理体验）；回灌第 2/3/4 层校验情绪供给是否连续

## 操作要点

### 1. 情绪家族分类表（常见被唤起状态）
| 情绪类别 | 典型词 | 通常由什么支撑 |
|---|---|---|
| 积极类 | 喜悦 / 愉悦 / 兴奋 / 期待 | 明亮色、暖调、动态、轻快节奏 |
| 安定类 | 宁静 / 松弛 / 安心 / 信任 | 大留白、低饱和、对称、柔和质感 |
| 向往类 | 浪漫 / 自由 / 憧憬 / 怀旧 | 氛围光、负空间、叙事性 imagery |
| 驱动类 | 紧迫 / 好奇 / 行动欲 | 强对比、指向性构图、CTA 焦点 |
| 认同类 | 共鸣 / 归属感 / 被理解 | 真实感、文化符号、贴近生活的场景 |

### 2. 四步定位法（设计情绪曲线）
1. **取感觉入口**：从本层「感觉」拿主感觉（如"轻盈"），确定情绪起点基调。
2. **定情绪曲线**：选一条曲线（见关键方法），标明起点→高点→终点各是什么情绪。
3. **对位故事节点**：把曲线节点对齐第 4 层「故事逻辑」的分章（起承转合）。
4. **映射供给手段**：每个情绪节点对应第 2/3 层手段（兴奋→撞色+动感构图；宁静→留白+低饱和）。

### 3. 维度五件套（情绪的验收坐标）
- **起点情绪**：第一感之后的第一情绪（好奇？宁静？）
- **曲线形状**：上升 / 波折 / 平复 / 陡降（是否完整不突兀）
- **高点情绪**：最被放大的情绪是什么
- **终点情绪**：停留/离场时的收尾情绪（应导向行动欲或认同）
- **连续性**：节点之间是否平滑过渡，有无断点

### 4. 关键方法与注意
- **情绪是一条曲线，不是一个点**：只定"要喜悦"不够，要设计"从___到___到___"的起伏。终点情绪尤其重要——它决定观众离场带走什么。
- **情绪节点 = 故事节点**：第 4 层故事逻辑的每一章，应对应一种情绪；故事断，情绪就断。
- **物料即情绪供给**：颜色冷暖、字重轻重、留白多少，都在持续供给情绪。第 2 层每个选择都要问"这供给的是什么情绪"。
- **气氛一致性**：整条曲线可以起伏，但**基调要统一**（不能前半浪漫后半硬核恐吓，除非是刻意的反转叙事）。
- **终点是行动或认同**：商业/传播设计，曲线终点应落到"行动欲"（紧迫/向往）或"认同"（共鸣）；纯艺术可只留余韵。
- **轻量 vs 商用**：个人项目凭直觉定曲线；商用项目建议画一张"情绪曲线图"做内部对齐，并在测试时问观众"你现在的感觉是___"。

### 5. 上下层 / 同层衔接
- **← 本层 感觉**：感觉是情绪的前置触发。
- **← 第 4 层 故事逻辑**：情绪曲线的骨架来自故事节奏。
- **← 第 2 层 物料 / 第 3 层 形式**：持续的情绪供给源。
- **→ 本层 心理体验**：情绪沉淀为深层的认同与记忆。
- **↺ 反推回 第 4/3/2 层**：情绪断点 → 回第 4 层修故事、第 3 层修动线、第 2 层修物料情绪。

- [ ] 情绪节点是否与第 4 层故事逻辑的分章对齐？
- [ ] 第 2/3 层是否在每个节点持续供给了对应情绪？
- [ ] 曲线基调是否统一（无突兀反转，除非刻意）？
- [ ] 终点情绪是否导向行动欲或认同（按需）？
- [ ] 感觉→情绪→心理体验三者是否连贯递进？
- [ ] 商用项目是否画了情绪曲线图并做了观众测试？
- [ ] 情绪目标是否已回灌并校验了第 2/3/4 层？

## 备注
- 情绪 ≠ 心理体验：情绪是**过程中的心情起伏**，心理体验是停留后沉淀的**认知与记忆**（"我认同这个""我要行动"）。情绪是过程，心理体验是结果。
- 与「故事逻辑」强耦合：故事节奏即情绪曲线，二者必须同构。
