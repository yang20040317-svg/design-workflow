# 第5层·主观输出 / 子位置：心理体验

> 所属工作流步骤：第 5 步（顺序：第一层 → 第二层 → 第三层 → 第四层 → 第五层）
> 本子位置是独立可编辑模块，可单独编写，不依赖其他子位置文件。

## 本子位置定位
- **层**：第 5 层 · 主观输出
- **子位置**：心理体验（psychological experience）
- **一句话说明**：观者停留后沉淀的**深层认知与记忆**——共鸣 / 认同 / 行动欲。它是设计的**长期价值**，也是整个五层工作流的**最终验收点**。
- **心智模型**：感觉是一秒，情绪是几秒，心理体验是**之后很久**。它回答一个终极问题："这个人离场后，带走了什么、记住了什么、愿意做什么？"它是前面四层所有努力沉淀出的**认知资产**——品牌印象、行动转化、情感连接，都在此落定。

## 在工作流中的位置（默认顺序 · 可跳层回补 + 反推 · 闭环终点）
- **正向（验收 · 流程终点）**：走完五层后，问三个问题——① 他**记住**了什么（记忆锚点）？② 他**认同**了吗（共鸣/归属感）？③ 他**愿做**什么（行动欲/转化）？三问能答，闭环成立。
- **反向（反推 · 最上游目标）**：心理体验其实是**最该先定的**。在动手前就问"我希望观众最终变成什么状态"（如"认同这是我的夏天，并想去购票"），再把这目标逐级反推：认同感→需要第 4 层"情感意图"+第 5 层"向往情绪"；行动欲→需要第 4 层"明确 CTA"+第 3 层"焦点引导"。
- **上一步输入**：本层「情绪」（情绪沉淀为心理体验）+ 第 4 层「表达意图」（意图的终局兑现）
- **本步要做**：明确最终心理目标（记忆/认同/行动），确认前四层已为其铺好路径
- **输出给**：验收交付（流程终点）；其结论可回灌任意前层做终校

## 操作要点

### 1. 心理体验家族分类表（深层认知结果）
| 体验类别 | 典型结果 | 主要由什么兑现 |
|---|---|---|
| 记忆类 | 记住品牌 / 记住一句话 / 记住画面 | 强主信息 + 独特视觉锤 + 第 3 层焦点 |
| 认同类 | 共鸣 / 归属感 / "这就是我" | 第 4 层情感意图 + 真实贴近的场景素材 |
| 行动类 | 购票 / 关注 / 分享 / 购买 | 第 4 层明确 CTA + 第 3 层指向性引导 |
| 情感类 | 被打动 / 温暖 / 力量感 | 第 5 层情绪曲线的高点兑现 |
| 口碑类 | 想分享 / 想讨论 | 记忆锚点 + 情绪高点 + 社交货币属性 |

### 2. 四步定位法（定最终体验目标）
1. **取意图终局**：从「表达意图」拿"想让观众做什么/成为什么"（认知→情感→行为）。
2. **定三类目标**：明确记忆目标（记住什么）+ 认同目标（认同什么）+ 行动目标（做什么）。
3. **查路径铺就**：逐项核对前四层是否为该目标铺了路（记忆→主信息焦点；认同→情感素材；行动→CTA 引导）。
4. **做终验三问**：记忆？认同？行动？三问能答即闭环；答不出则定位断点层回修。

### 3. 维度五件套（心理体验的验收坐标）
- **记忆锚点**：有没有一个让人忘不掉的点（一句话/一个画面）？
- **认同深度**：观众是否感到"这说的就是我/我的事"？
- **行动清晰**：离场后他清楚该做什么吗（CTA 是否明确）？
- **情感余韵**：走后还留着什么情绪温度？
- **一致性**：记忆/认同/行动三者是否指向同一主轴（无分散）？

### 4. 关键方法与注意
- **先定终局，再反推全程**：心理体验是闭环终点，但**目标要最早定**——它是一切前层决策的"最终裁判"。
- **三问即验收**：记忆？认同？行动？这是五层流程的**交付检查单**，比"好不好看"更硬。
- **记忆靠视觉锤**：让人记住不靠说得多，靠一个强焦点（第 3 层构图焦点 + 第 2 层独特物料）。
- **认同靠真实贴近**：共鸣来自"像我的生活"，第 2 层素材要真实、第 4 层意图要诚恳，假大空触发防御。
- **行动靠降低门槛**：CTA 要单一、醒目、零犹豫（第 3 层焦点 + 第 4 层行动意图）。
- **三层目标可分层达成**：不是每个设计都要三者满分——传播设计重记忆+行动，品牌设计重认同+记忆，艺术重情感余韵。按「表达意图」定优先级。
- **轻量 vs 商用**：个人/测试项目凭三问自测即可；商用项目建议做回访（"你还记得它讲啥吗？你想做啥？"）验证心理体验是否真发生。

### 5. 上下层 / 同层衔接
- **← 本层 情绪**：情绪沉淀为心理体验（过程→结果）。
- **← 第 4 层 表达意图**：意图的终局在此兑现，意图是心理体验的"施工图"。
- **← 第 1~3 层**：记忆锚点靠第 3 层焦点、认同靠第 2/4 层真实素材、行动靠第 3/4 层引导——全层在此汇总。
- **→ 验收交付（终点）**：三问成立即交付；结论可回灌任意前层做终校。

## 备注
- 心理体验是**闭环终点也是目标源头**：作为终点它验收全流程，作为源头它最早定调反推全程。这正是五层"自顶向下规划、自底向上验收"的合拢处。
- 与「表达意图」首尾呼应：意图是准星（起点），心理体验是命中的靶（终点）。
