# 第4层·信息叙事 / 子位置：故事逻辑

> 所属工作流步骤：第 4 步（顺序：第一层 → 第二层 → 第三层 → 第四层 → 第五层）
> 本子位置是独立可编辑模块，可单独编写，不依赖其他子位置文件。

## 本子位置定位
- 层：第 4 层 · 信息叙事
- 子位置：故事逻辑
- **一句话说明**：阅读 / 体验的顺序与节奏，需与视觉流向吻合。
- 心智模型：**设计不是把信息摊开，是讲一个让人顺着走的故事。** 视觉流向就是故事线——观者眼睛被带去的先后，就是故事讲的先后。

## 在工作流中的位置（默认顺序 · 可跳层回补）
- 上一步输入：第 3 层「排版构图（视觉流向/动线）/ 镜头布局（镜头次序）」+ 同层「信息优先级」（主信息=起点）
- 本步要做：设计观者的阅读路径与情绪节奏——第一眼看哪、顺着什么走、在哪停顿、最后落到哪（行动）
- 输出给：同层「表达意图」（故事服务意图）；第 5 层（故事节奏 = 情绪曲线）

## 操作要点

### 1. 叙事结构分类表
| 结构 | 适用 | 路径 |
|---|---|---|
| **线性叙事** | 大部分海报/详情页 | 起点→发展→高潮→行动，单线到底 |
| **问题—解决** | 产品/说服型 | 痛点→方案→证据→行动 |
| **对比** | before/after、选择 | A 与 B 并列对照，结论在中间或末尾 |
| **时间轴** | 历程/预告 | 沿时间从左到右/上到下 |
| **中心辐射** | 品牌/主张 | 中心一个核，四周支撑点 |
| **环形/回环** | 活动/社群 | 终点回到起点，强调循环参与 |

### 2. 具体怎么操作（四步定位法）
1. **定起点（第一眼）**：用「信息优先级」的主信息作钩子，第一眼就抓住（呼应第 3 层视觉重心）。
2. **定路径**：规划视线从主信息流向次信息再到底部行动，用引导线/明暗/大小梯度铺路（呼应排版构图「视觉流向」、镜头布局「虚拟运镜」）。
3. **定节奏（张弛）**：用留白做"停顿"、用密集做"加速"；高潮处给最大空间，细节处可紧凑。
4. **定终点（行动）**：故事收在"你想让他做什么"（扫码/购票/记住），位置要稳、可顺路到达。

### 3. 维度五件套
- **起点吸引力**：第一眼钩子是否够强（主信息/视觉奇观）
- **路径清晰度**：视线是否被明确带路，无歧路迷路
- **节奏张弛**：有无停顿与加速，避免全程一个调
- **终点行动**：故事是否收在明确行动点
- **回环呼应**：结尾是否呼应开头（强化记忆/参与）

### 4. 关键方法
- **视觉流向即故事线**：视线被带到的先后 = 故事讲的先后，与第 3 层「排版构图·视觉流向」「镜头布局·镜头次序」完全对齐，不在本层另起炉灶。
- **起承转合**：好故事有起伏——开场钩子（知）、中段铺陈（感）、高潮主张（信）、收尾行动（做）。
- **钩子在起点**：第一眼必须有个"为什么看下去"的理由（悬念/美感/利益）。
- **留白作停顿**：故事不是连珠炮，留白处让观者喘气、消化，再进入下一段（呼应第 3 层空间）。
- **终点不迷路**：行动指令（CTA）要顺路径自然到达，别让观者看完不知道干啥。
- **反套路慎用**：常规结构最稳；故意打乱顺序要有强理由，否则观者流失。

### 5. 上下层 / 同层衔接
- **← 第 3 层**：排版构图（视觉流向/动线）、镜头布局（镜头次序=叙事次序）提供"怎么带视线"的手段。
- **← 同层 信息优先级**：主信息=故事起点/钩子。
- **→ 同层 表达意图**：故事结构必须服务意图（告知/说服/情感/行动）。
- **→ 第 5 层**：故事节奏 = 情绪曲线（紧张/松弛/高潮对应情绪起伏）。
- **↔ 第 1 层**：场景/环境决定阅读时长（快刷载体故事要短平快）。

## 自检清单
- [ ] 起点钩子是否够强、第一眼抓人？
- [ ] 视线路径是否清晰、无迷路歧路？
- [ ] 节奏是否有张有弛（留白停顿 + 密集加速）？
- [ ] 故事是否收在明确行动点（CTA）？
- [ ] 叙事结构是否与「信息优先级」主信息一致？
- [ ] 是否与第 3 层视觉流向/镜头次序吻合（不另起炉灶）？
- [ ] 故事是否服务「表达意图」？
- [ ] 输出「故事线」是否能被第 5 层用作情绪曲线？

## 备注
- 故事逻辑 ≠ 排版构图：排版定"视线怎么走"（动线技法），本模块定"为什么要这样走"（叙事意图）。技法是手段，叙事是目的。
- 与「表达意图」强耦合：故事是意图的载体；与「信息优先级」强耦合：先讲=主信息。
