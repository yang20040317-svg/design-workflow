# 第4层·信息叙事 / 子位置：信息优先级

> 所属工作流步骤：第 4 步（顺序：第一层 → 第二层 → 第三层 → 第四层 → 第五层）
> 本子位置是独立可编辑模块，可单独编写，不依赖其他子位置文件。

## 本子位置定位
- 层：第 4 层 · 信息叙事
- 子位置：信息优先级
- **一句话说明**：主 / 次 / 辅信息的视觉权重分配，禁止平均主义。
- 心智模型：**所有信息生而平等，但视觉上必须不平等。** 平均主义 = 没有重点 = 观者什么都记不住。设计的功力一半在"敢让次要信息退后"。

## 在工作流中的位置（顺序执行）
- 上一步输入：第 1 层「场景/客观约束」+ 第 3 层「关系（主次权重）/ 排版构图（重细对比）/ 空间」
- 本步要做：把要传达的信息全部列出，分级为 主 / 次 / 辅，分配各自视觉权重（大小/位置/对比），确保第一眼抓到主信息
- 输出给：同层「故事逻辑」（主信息=故事起点）、「表达意图」（主信息=意图核心）；第 5 层（主信息决定记忆点）

## 操作要点

### 1. 信息角色分类表
| 角色 | 定义 | 视觉权重 |
|---|---|---|
| **主信息** | 一句话核心，没有它设计失去意义（如活动名/品牌/主张） | 最大、最醒目、唯一焦点 |
| **次信息** | 支撑主信息的关键要素（如日期/地点/价格/卖点） | 中等，清晰可读但不抢 |
| **辅信息** | 补充细节（如细则/鸣谢/二维码说明） | 最小，退到最后 |
| **装饰信息** | 纯氛围（英文点缀/水印/纹理字） | 不参与信息层级 |

### 2. 具体怎么操作（四步定位法）
1. **列全清单**：把客户/需求方给的所有文字信息摊开，不漏（含隐性要求）。
2. **强制分级**：逐条问"少了它设计还成立吗？"——成立则降一级，不成立则升主级。主信息通常只有 1 个。
3. **定视觉权重**：主信息给最大面积/最强对比/最佳位置；次信息靠层级间距与主信息分组；辅信息压到角落。
4. **落位分配**：把权重交回第 3 层「排版构图/关系」去落位（重细对比、间距亲密性）。

### 3. 维度五件套
- **主信息唯一性**：是否只有 1 个不可动摇的焦点（避免双主争抢）
- **层级级数**：通常 3 级足够（主/次/辅），过多反而乱
- **面积占比**：主信息占据视觉面积是否压倒性（如 ≥30% 焦点区）
- **对比强度**：主 vs 次 的对比（字重/色/大小）是否一眼可辨
- **阅读次序**：视线第一落点是否就是主信息

### 4. 关键方法与注意
- **禁止平均主义**：绝不把所有信息做成同样大小同样颜色——那是信息图表不是设计。
- **主信息唯一**：一张图只能有一个"第一眼"。双主信息 = 无主信息。
- **3 级足够**：主/次/辅三级最稳；非要到 4 级也要靠间距拉开。
- **权重交回排版**：本模块定"谁重要"，第 3 层「排版构图」的"重细对比"和「关系」的"亲密性"负责把它做出来，不重复劳动。
- **与场景呼应**：第 1 层若定"信息流快刷"，主信息要更大更狠；若"户外远观"，主信息对比度拉满。
- **商用转化视角**：主信息往往是转化钩子（如"限时 5 折"），轻量模式可弱化此视角。

### 5. 上下层 / 同层衔接
- **← 第 1 层**：场景/客观约束决定信息密度上限（快刷载体信息要少）。
- **← 第 3 层**：关系（主次权重）、排版构图（重细对比）、空间（层级间距）提供落位手段。
- **→ 同层 故事逻辑**：主信息 = 故事起点，先被看到先被讲。
- **→ 同层 表达意图**：主信息 = 意图核心（想让人记住的那句）。
- **→ 第 5 层**：主信息决定观者"记住什么"，是体验的记忆锚点。

## 自检清单
- [ ] 是否列出了全部信息、无遗漏？
- [ ] 是否强制分级，主信息只有 1 个？
- [ ] 是否杜绝了平均主义（大小/对比有差）？
- [ ] 第一眼落点是否就是主信息？
- [ ] 层级是否 ≤3 级且清楚可辨？
- [ ] 权重是否已交回第 3 层落位？
- [ ] 是否与第 1 层场景/载体密度匹配？
- [ ] 输出「优先级表」是否能被故事逻辑/表达意图直接使用？

## 备注
- 信息优先级 ≠ 排版构图：本模块定"谁重要"（决策），排版构图定"怎么摆出来"（执行）。先决策后执行。
- 与「表达意图」强耦合：意图核心往往就是主信息；与「故事逻辑」强耦合：先讲=主信息。
