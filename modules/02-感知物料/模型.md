# 第2层·感知物料 / 子位置：模型

> 本子位置是独立可编辑模块，可单独编写，不依赖其他子位置文件。

## 本子位置定位
- 层：第 2 层 · 感知物料
- 子位置：模型
- 一句话说明：3D / 空间模型、材质光照、可交互性（产品 / 空间 / 角色 / AR）
- **心智模型**：模型是第 2 层的「三维延伸」——当设计需要 **体积感、可旋转、可交互、或空间叙事** 时，平面物料（图片 / 颜色 / 文字）不够用，用模型承载。它不是「更高级的图片」，而是一种 **自带空间与相机** 的物料：你不仅要决定它长什么样，还要决定它怎么被看（机位 / 光照 / 能否转动）。

## 在工作流中的位置（顺序执行）
- 上一步输入：第 1 层的「载体」（是否支持可交互 3D？还是只出静帧图）、「环境」（真实光照参考）、「客观约束」（商用模型授权红线）
- 本步要做：决定本设计要不要上 3D、上什么类型、什么精度、什么交付形态；产出模型规格（建模类型 / 风格 / 面数预算 / 机位 / 光照）或直接产出模型资产
- 输出给：第 3 层「空间 / 镜头布局」（模型自带体积，决定机位与构图）、第 3 层「排版构图」（3D 元素与平面文字的混排）；同层喂给「颜色 / 纹理」（材质配色与表面质感）

## 操作要点

### 1. 模型家族分类（按用途选对形态）
| 类型 | 典型用途 | 常见形态 | 工具倾向 |
|---|---|---|---|
| 产品 / 物件模型 | 电商、包装 3D 化、产品展示 | 写实或精致风格化单体 | Blender / C4D / 犀牛 |
| 角色 / 吉祥物 | IP、品牌拟人、活动 mascot | 风格化中模，可绑定表情 | Blender / ZBrush / Nomad |
| 场景 / 空间 | 室内、建筑、等距插画场景 | 等距（isometric）或透视空间 | Blender / C4D / Spline |
| 3D 图标 / UI | 应用图标、界面立体元素 | 低面数、干净材质 | Blender / Spline |
| 可交互 / AR 模型 | 网页可旋转、AR 试穿试摆 | 轻量 glTF，需优化 | Spline / Three.js / USDZ |
| 抽象 / 生成几何 | 数据艺术、粒子、流体氛围 | 程序化、非写实 | Houdini / Blender 几何节点 |

> 选错形态 = 白做。海报 / 社媒多用「风格化 + 等距 / 低模」又快出效果；电商 / 产品页才上写实高模。

### 2. 四步定位法（确定要做什么模型）
1. **定目的**：只是氛围点缀（静帧渲染）？还是要让用户旋转查看（可交互）？或是空间叙事（场景）？目的决定后面所有选择。
2. **定类型**：写实 / 风格化 / 低模卡通 / 等距。品牌年轻活泼 → 风格化低模；高端产品 → 写实 PBR。
3. **定复杂度**：面数预算与是否需贴图。社媒图一张静帧可高面；网页可交互必须低面数 + 压缩。
4. **定交付格式**：
   - 静帧展示 → 渲染成 `PNG/JPG`（当作图片物料进第 3 层）
   - 网页可旋转 → `glTF / GLB`（Three.js / Spline 加载）
   - 工程继续改 → `FBX / OBJ / BLEND`
   - 移动 AR → `USDZ`（iOS）/ `glTF`（安卓）

### 3. 维度五件套（描述一个模型的五个角度）
- **几何精度**：高模写实（细节多、慢）↔ 低模卡通（面少、快、有设计感）
- **材质光照**：PBR（金属度 / 粗糙度，真实布光）↔ 卡通着色 Toon（平涂、省时、出「设计味」）；是否要环境光遮蔽 AO 增强体积
- **风格化**：等距 / 低面 / Toon / 半写实 / 写实，统一全项目
- **可交互性**：静态渲染 ↔ 可旋转 ↔ AR 试摆，逐级增加成本
- **性能预算**：三角面数、纹理尺寸、能否在目标端流畅跑（见关键方法）

### 4. 关键方法与注意
- **风格化优先于写实**：多数设计场景（海报 / 社媒 / 品牌）用风格化低模 + 等距，比写实 PBR 更出「设计感」且快数倍。写实留给电商 / 产品。
- **材质光照速选**：
  - 要干净现代感 → 卡通着色 + 单主光 + 补光
  - 要体积真实感 → PBR + HDRI 环境光 + AO
  - 出图前加 **AO 与边缘光**，体积感立刻出来
- **性能预算红线（网页 / 移动端可交互）**：
  - 三角面 ≤ 100k（移动端更严可压到 30–50k）
  - 纹理 ≤ 1k–2k，用 draco / meshopt 压缩 glTF
  - 单模型包体尽量 < 5MB，否则加载即流失
- **与平面物料混排**：3D 常作「主角」，2D 文字 / 图片作衬托。注意 **透视与光照一致**（平面元素别和 3D 光源打架）；3D 投下的阴影要落到平面底上才站得住。
- **工具链速查**：Blender（免费全能）、C4D（动效友好）、Spline（网页可交互零代码）、Houdini（程序化 / 生成艺术）、Nomad（iPad 雕刻）、Rhino（工业 / 珠宝）。
- **无障碍与版权**：可商用模型去 Sketchfab / Quaternius / Poly Haven（标 CC0 / 可商用）；复杂可交互模型要提供 **静帧降级图**，避免低端设备 / 弱网白屏；AR 注意设备兼容。

### 5. 从参考图到模型的执行流程（当任务 = 照着一张图做出模型）

> 上面 1~4 解决"要不要上 3D、上什么"；本小节解决"**照着参考图怎么把它做出来**"。通用执行/验收机制（源自"参考图 → 程序化 3D 资产"类质量闸门工作流，已去域化）。来源署名见 `references/来源署名/vinhhien112-img2obj.md`。

#### 四阶段渐进（顺序不能反）

| 阶段 | 目标 | 该做什么 | 明确不该做 |
|---|---|---|---|
| **1. Blockout 轮廓** | 收敛主视图剪影与宏观比例 | 几何可以粗，但所有**身份性主要部件**必须存在且位置合理 | 不做细节计划、不做贴图、不做绑定轴心 |
| **2. Form 结构** | 结构、附着、局部形状、配重、signature 细节 | 递归分解；重复/附着系统须声明**父级 + 接触/重叠/间隙**意图 | 不破坏已验收的 Blockout 层 |
| **3. Lookdev 材质** | 颜色分区、材质类别、光泽、微起伏、光照、接地阴影 | 各通道**独立取证**（颜色/粗糙度/高度/法线/AO） | **禁止把颜色图当别的通道复用**；剪影级起伏用几何，剪影之下的细节才用材质 |
| **4. Interaction 可动** | 轴心、轴向、限位、关键状态、运行时证据 | 即便用户没要求动画也**必须评估**：有明确关节/领域先验 → 实现；没有 → 明写"不需要"并给理由 | **不许发明**物理、破坏、隐藏机关 |

#### 渐进式规格：稳定核心 + 阶段增量

- **稳定核心**（一直加载）：目标与所观察的参考、坐标系与相对尺度、主剪影/比例/地标/负空间、稳定语义 ID 与宏观层级、有界假设与已知风险、**唯一权威参考图**。
- **阶段增量**（各阶段自己写）：只写当前阶段那一份 delta。
- **不要在第一次渲染之前把最终规格写满**——早写满 = 早把自己锁死在没被验证的假设上。

#### 单循环

`影响评估 → 只改挑战者 → 构建/渲染 → 与唯一权威参考图并排比对 → 双评审 → 晋级/回滚 → 人工批准`

#### 门禁要点

- **唯一权威**：参考图是唯一验收标准。合成的辅助视图 / 线框图 / 规划图**只能否证、不能证明**——它能暴露不合理的结构，但绝不能用来判定"像"。
- **证据范围错配**：拿"局部模块渲染"去比对"整体参考图"是无效配对，**不得打分、不得消耗重试次数、不得触发回滚**。
- **冠军 / 挑战者**：修改只作用于挑战者，冠军不动；失败事务性回滚。
- **三连无改进 = 策略耗尽**：保留冠军，明记一次「策略重置」，必须**换表示法**再试，不许原地磨。
- **未观察到的部分**（背面、被遮挡结构、推测尺寸）一律记为「有界假设 / 已知风险」，**不当事实写**。
- **验收机制**走主技能 `05-主观输出/感觉.md`「补充 · 视觉验收的双评审闸门」（盲 scout + 关键特征否决制）。

#### 能力分支按需加载

植被 / 硬表面机械 / 有机皮肤 / 毛发纤维 / 织物 / 透光 / 地形 / 运动 / 发光体积 / 贴花标记——**命中哪个加载哪个**。禁止预载全部，禁止把整个物体强行归成某一类（一台机器可以同时有硬表面 + 织物 + 发光）。

#### 明确不适合（该说不）

单张图给不出隐藏面与精确尺寸；程序化产出是**近似重建**不是扫描/提取；透明玻璃、烟雾、液体、毛发、精细布料、精确肖像通常需要**更多参考或主动降低目标精度**。做不到就明说，不要静默替换成猜出来的东西。

### 6. 上下层与同层衔接
- **← 第 1 层**：载体决定「能否可交互」（网页 / App 才行，印刷海报只能出静帧）；环境给真实光照参考；客观约束商用模式才查模型授权红线。
- **→ 第 3 层**：模型自带空间，直接喂给「空间」（占据多少负空间）、「镜头布局」（需要什么机位 / 景深）、「排版构图」（3D 与平面文字层级）。
- **↔ 同层**：颜色（材质贴图配色）、纹理（表面粗糙度 / 质感）、图片（背景合成 / 实拍 + 3D 合成）。

- [ ] 【照着参考图做模型时】是否按四阶段渐进（Blockout 轮廓 → Form 结构 → Lookdev 材质 → Interaction 可动），未跨阶段提前做后面的事？
- [ ] 是否指定了**唯一权威参考图**？合成/辅助视图是否被正确限定为"只能否证不能证明"？

## 备注
- 模型 ≠ 图片：它多出「相机与空间」两个自由度，所以第 3 层「镜头布局」「空间」会频繁回调本子位置的机位与体积决策。
- 若设计明确是纯 2D（如扁平插画海报），本子位置标 **N/A**，不强行上 3D。
