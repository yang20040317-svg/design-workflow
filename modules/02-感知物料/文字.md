# 第2层·感知物料 / 子位置：文字

> 本子位置是独立可编辑模块，可单独编写，不依赖其他子位置文件。

## 本子位置定位
- 层：第 2 层 · 感知物料
- 子位置：文字
- 一句话说明：字库、字号层级、字重、行距、语气、版权（中文尤其注意字体可用性与授权）
- **心智模型**：文字是第 2 层的「信息骨架」——图片负责吸引与氛围，**文字是唯一能精确传递语义的物料**：活动名称、时间、地点、利益点，最终都靠文字落地。再好的图，缺了文字就只是情绪；文字对了，信息才立得住。

## 在工作流中的位置（默认顺序 · 可跳层回补）
- 上一步输入：第 1 层的「载体」（决定最小可读字号 / 观看距离）、「环境」（光线决定对比底线）、「客观约束」（商用模式才查字体授权红线）
- 本步要做：选定字库与字重体系、定信息主次、控字号阶梯与可读性；产出「文字规格」（字体调性 / 字重层级 / 字号阶梯 / 字距行距 / 版权状态）
- 输出给：第 3 层「排版构图」（文字放哪、占多大、主次要层级）；同层喂给「颜色」（文字色）、「图片」（图文层级）

## 操作要点

### 1. 文字角色分类（先分清楚这句话是干嘛的）
| 角色 | 作用 | 典型处理 |
|---|---|---|
| 主标题 | 第一眼抓注意、定调性 | 重字重 / 最大字号 / 醒目字体 |
| 副标题 | 承接主标题、补充定位 | 中字号、中等字重 |
| 正文 / 说明 | 传递细节信息 | 常规字重、易读优先 |
| 标签 / 徽章 | 分类、强调关键词 | 小字号、反白或描边块 |
| 数据 / 数字 | 突出关键量化（价格 / 日期 / 人数） | 大号数字、对比色 |
| 口号 Slogan | 情绪记忆点 | 个性化字体（手写 / 圆体） |
| 装饰字 | 纯氛围、非信息 | 弱化、作背景 |

> 一句话里先分角色，再定层级——这是文字不「糊成一团」的前提。

### 2. 四步定位法（确定文字系统）
1. **定信息角色**：哪些字是主、哪些是辅、哪些只是装饰（见上表）。
2. **定字体调性**：随性亲切→手写体；经典高级→衬线体；现代简洁→无衬线；可爱→圆体。调性要呼应第 4 层表达意图。
3. **定字重层级**：主用重字重 / 粗体，辅用纤细字体——**层级靠「重 vs 细」拉开，不靠字号堆**。
4. **定规格与版权**：最小可读字号（依载体观看距离）、字距行距、字体来源（商用模式必查授权）。

### 3. 维度五件套（描述一套文字系统的五个角度）
- **字体选择**：衬线 / 无衬线 / 手写 / 圆体 / 美术字，全项目统一主字体 + 1 个对比字体
- **字重对比**：重（主）↔ 细（辅），这是层级的核心杠杆
- **字号阶梯**：建立 3–5 级阶梯（如 主48 / 副28 / 正文16 / 说明12），跳级不乱
- **行距与字距**：标题紧字距显凝聚，正文宽松行距保可读；中文注意标点与避头尾
- **可读性与对比**：文字与底图 / 底色对比度达标（见第 1 层环境底线），弱光 / 远观场景加粗加大

### 4. 关键方法与注意
- **「重 vs 细」拉层级（核心）**：主标题重字重粗体，辅助文案纤细——层级靠对比，不靠一味放大。放大只会挤占空间。
- **大字手写体弱化机械感**：大字手写体配实景底图可弱化机械生硬感，让标题「长」得自然、有温度（适合文创 / 活动 / 手账风）。
- **中英文混排**：中文用中文标点与字距逻辑，英文 / 数字用西文间距；英文小字可作副信息补白（如英文活动名衬在主标题下）。
- **文字压图保对比**：文字压在花图 / 照片上时，加底块（半透明黑 / 主色块）或压暗角，保证可读性；避免文字直接落在杂乱区域（见同层「图片」安全区）。
- **字体版权（呼应第 1 层红线双模式）**：
  - 轻量模式（个人 / 测试 / 自娱）：自己能用的字体即可，不强制查授权。
  - 商用模式：走可商用白名单（思源黑体 / 思源宋体 / 站酷系列 / 霞鹜文楷等免费可商用；或已购授权）。**中文尤其注意**——很多「好看的中文字体」个人免费、商用需授权，务必确认。
- **无障碍字号下限**：正文中文字号不宜过小（移动端 ≥ 14px 较稳），弱光 / 远观场景再放大；色弱人群避免仅靠颜色区分文字。

### 5. 上下层与同层衔接
- **← 第 1 层**：载体决定最小可读字号与观看距离（户外大屏字要巨、手机信息流字要清）；环境定对比底线；客观约束商用模式才查字体授权。
- **→ 第 3 层**：文字规格直接喂给「排版构图」——放哪、占多大、主次要层级如何排布；字块「长」进画面的处理在文字层定调、在构图层落位。
- **↔ 同层**：颜色（文字色 / 反白块）、图片（图文层级、压图对比）。

## 补充 · 社交卡片类通用规则

> 以下来自社交卡片生成类任务的通用经验，去 IP 化后并入本子位置，与上方通用原则不冲突、作增量补充（来源署名见 `references/来源署名/op7418-guizang-social-card.md`）。

- **越大越细（反比规则）**：标题进入 Display 级超大字号时，字重必须**下降**（更细），而非加粗。字号↑→字重↓，二者反比；超大粗体会显笨重、挤占且失优雅。正文/标签仍按各自层级。
- **双字体系统**：全项目用「衬线（叙事/气质）+ 无衬线（结构/信息）」两套覆盖中英，主字体 + 1 对比字体即可，不堆更多字体。
- **大标题行数预算**：Display 标题行数受画板高度预算限制，超行溢出风险高；定稿前确认行数在画板内。
- **标题间隙**：大标题与下一块内容之间必须保留明确间隙（防贴合），间距不小于标题字号的 0.3–0.5 倍。

## 补充 · 图形字（合字）作为文字物料

> **已抽离为专项子技能** `subskills/design-typographic-glyph`。字不只是"读什么"，也可以是"看什么"——图形字/合字/pictogram typography 是把具象图形寄进汉字骨架、与字共生成新视觉单元（文创/海报/节令物产/系列图标常用）。完整方法（何时用、合字字体选型、以字寄形、墨朱三色制、三个不能踩、设计三轴、系列化延展、双重可识别验收）见该子技能 SKILL.md。

> 本文件保留「文字层视角」的三条快速判定：
> - **合字友好字体**：书法体/北碑体/颜楷/褚体/篆意美术字（骨架粗壮、笔画可借用），非细瘦几何体。
> - **三个不能踩**：图字不相干=退化配图；图毁字=吃掉中宫位；多色过载=超墨朱丢调性。
> - **商用红线**：单字/合字整体视觉版权属字体作者，不在"技法免费"清单内。

> **前置判定（是否切到图形字子技能）**：进入本层先问一句——"这个设计里的汉字，是只用来读信息，还是同时要当视觉主体？"若汉字本身就是画面主角（字即图 / 书法构成主视觉 / 字与图形共生），**不要只当普通文字物料处理**，直接路由 `subskills/design-typographic-glyph`；只有纯信息传递（标题、正文、说明）才走常规字库流程。

> 配套分工：文字层定**字库选择、墨朱色制、文字可识别门槛**；共生位置/笔触共享/面积配比/套系延展 → `design-typographic-glyph`；图底/印章/视觉权重 → 关系层（见 `03-形式组织/关系.md`）。

## 补充 · 三字体系统（sans / mono / display）

> 完整方法见 `subskills/design-metaphor-narrative` 第六节。核心：**分工即语义**——sans（比例）承载人类叙述；mono（等宽）承载机器读数（坐标 / 时间 / 编号 / 标签，天然带票据与仪表盘联想）；display（特征字体，如数码管）**仅**用于数字读数。判据：同一信息换个字体就"不像那个东西了"，分工即生效。
> ⚠️ 只借分工思路，具体字体须自选可商用替代（勿套用他站自有字体文件）。

## 补充 · 字感（字体匹配主题气质）

> 来源：公众号「字有分寸」2026-08-31《中文排版没有设计感？…》（与 `03-形式组织/排版构图.md` 的「补充 · 排面」同源，本段只取"字感"侧；属模式 1 排版知识增量，非模式 2 品味）。

- **字感 = 选的字是否视觉化、字库是否匹配主题气质调性**：字体选择不是"好看就行"，而要呼应内容气质（随性→手写、经典→衬线、现代→无衬线，见上方「定字体调性」）。把"匹配主题"从隐含直觉提升为显式判据。
- **与排面配合**：字感管"用哪类字"，排面（文字的空间排布，见 `03-形式组织/排版构图.md`）管"怎么摆"；两者共同决定排版的设计感。

## 备注
- 「重细对比」「手写体弱化机械感」等**文字系统的定调**归本模块；而把这些字块**排布成层级、长进画面**的落位归第 3 层「排版构图」——两层分工，不要越界。
- 文字是第 4 层「信息叙事」的物质载体：第 4 层决定「说什么、谁先说」，本层决定「用怎样的字说、主次如何」。
