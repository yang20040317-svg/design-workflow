# 第2层·感知物料 / 子位置：动画

> 所属工作流步骤：第 2 步（顺序：第一层 → 第二层 → 第三层 → 第四层 → 第五层）
> 本子位置是独立可编辑模块，可单独编写，不依赖其他子位置文件。

## 本子位置定位
- 层：第 2 层 · 感知物料
- 子位置：动画
- 一句话说明：把**运动**当作一种物料——转场、微交互、节奏、引导、氛围，让静态元素活起来、把信息讲清楚
- 心智模型：动效不是"最后加一层装饰"，它是和颜色 / 文字 / 图片并列的**第六种感知物料**。同样一块画面，会不会动、怎么动，决定了用户"看见什么、先看见什么、有什么感觉"。动画承载三件事：**状态**（东西在加载 / 已提交 / 出错）、**引导**（眼睛被带到哪）、**情绪**（轻快 / 沉稳 / 紧张）。

## 在工作流中的位置（顺序执行）
- **上一步输入**：第 1 层「场景」产出——
  - 载体规格卡里的「交互与动态能力」（什么格式才"动得起"：mp4 才有动画、svg 可 css 动、web 可 lottie、印刷品则完全不能动）；
  - 环境里的「观看情境」（移动中看 → 动效要做短做亮；公众大屏 → 可循环氛围；噪声环境 → 别靠动效传关键信息）；
  - 客观约束里的「性能红线」（低端机 fps 下限）与「无障碍要求」（是否必须支持减弱动效）。
- **本步要做**：决定画面里**动什么、怎么动、动多久、谁触发**，产出可落地的动效规格（时长 / 缓ing / 触发 / 时序 / 性能预算），并明确哪些元素需要动、哪些静止。
- **输出给**：
  - 第 3 层「形式组织」——镜头运动、空间位移、时间轴上的构图节奏都建立在"动"的规格上；
  - 第 4 层「信息叙事」——动效的先后次序（先亮标题再亮正文）就是叙事的先后次序；
  - 本层其他子位置——文字如何入场、图片如何过渡、颜色如何呼应动效，归本模块调度。

## 操作要点

### 一、动画家族分类（先定位"动哪一类"）
先判断这段动效属于哪一族，类型定错后面全错。

| 家族 | 干什么用 | 典型场景 | 常见手法 |
|------|----------|----------|----------|
| **转场过渡** | 连接两个状态 / 页面 / 章节 | 页面跳转、卡片展开、章节切换 | 淡入淡出、滑动、推压、共享元素 |
| **微交互反馈** | 告诉用户"你操作成功了 / 正在处理" | 按钮按下、点赞、加载、提交 | 缩放回弹、骨架屏、进度环、toast |
| **引导与强调** | 把视线引到关键处 | 新功能引导、错误高亮、滚动揭示 | 脉冲、路径动画、视差、依次浮现 |
| **循环与氛围** | 让画面"活着"，不传达具体信息 | 背景流光、待机动画、品牌呼吸感 | Lottie 循环、粒子、缓动漂浮 |
| **数据 / 状态可视化** | 让数字与状态自己说话 | 计数器、进度、图表生长、仪表盘 | 数值滚动、路径描边、条形增长 |
| **叙事故事** | 用一连串动作讲一段内容 | 开场序列、插画角色动起来、loading 剧情 | 关键帧序列、逐帧、场景调度 |

### 二、四步定位法（按流程一步步做）
1. **定目的**：这段动效到底要解决什么——引导注意 / 反馈操作 / 装饰氛围 / 讲清数据 / 叙事？一句话说不清目的，就先别动。
2. **选类型**：对照上表归类，锁定家族与"常见手法"方向。
3. **定节奏**：时长多长、缓动曲线、先后次序（谁先谁后、是否 stagger）。
4. **估预算**：低端机能否 60fps？文件体积是否超标（Lottie / MP4 / 序列帧各自上限）？是否触碰第 1 层性能红线？

### 三、维度五件套（每次动效必查）
- **时长 Duration**：微交互 100–300ms，转场 200–500ms，氛围循环 2–8s；越长越"重"，越短越"利落"。
- **缓动 Easing**：极少用线性；默认 `ease-out`（进场利落），离开用 `ease-in`，弹性用 `back`/`spring`。
- **触发 Trigger**：用户触发（点击 / 悬停）/ 系统触发（加载完成 / 数据到达）/ 自动（进场 / 循环）。触发错了动效会"乱动"。
- **时序 Sequence**：单元素顺序、多元素 stagger（错峰）、并行；决定"信息先后"= 叙事先后。
- **性能 Performance**：只动 `transform` / `opacity`（GPU 友好），避免动 `width/height/top`（触发重排）；目标 60fps，Redmi 级低端机也要保底 30fps。

### 四、关键方法
- **缓动速查表**

  | 想表达的感觉 | 曲线 | 适用 |
  |--------------|------|------|
  | 利落进场 | `ease-out` / `cubic-bezier(.2,.8,.2,1)` | 弹窗、卡片入场 |
  | 平稳离开 | `ease-in` | 元素退出、收起 |
  | 有弹性 / 俏皮 | `back-out` / `spring` | 点赞、成功反馈 |
  | 机械 / 线性 | `linear` | 进度条、加载环（非装饰） |

- **指数平滑追随手感（帧率无关的跟手公式）**
  - 公式：`v += (target − v) * (1 − exp(−k · dt))`（等价 `lerp(v, target, 1 − exp(−k·dt))`）——比固定 `lerp(0.1)` 更高级：**帧率无关**，任何刷新率下手感一致。
  - 参数：k 越大跟得越紧（相机视差 k≈3.5 / 磁吸 k≈10 / 惯性滚动衰减 k≈3）。
  - 用途：相机跟随、磁吸倾斜、指针追踪、任何"追目标"的平滑；与缓动速查表互补——曲线表管"一次运动的缓入缓出"，本公式管"持续追随的手感"。
  - 同族：惯性衰减 `v *= exp(−k·dt)` 是"停"，本公式是"跟"。

- **性能预算红线**
  - 只动 `transform` 与 `opacity` 两个属性，远离布局属性（`top/left/width/height`）。
  - 格式选型：轻量循环用 **Lottie**（json，体积小可无限缩放）；长动画用 **MP4/H.264**（注意体积）；逐帧精致用**序列帧**（最重，慎用）；Web 内优先 CSS / WAAPI，复杂用 Lottie / Canvas。
  - 数量克制（**默认预算**）：同屏同时运动元素**默认 ≤3–5 个**，多了画面就"噪"。**破格触发器**：画面有且仅有一个视觉焦点 / 某元素承担 signature 记忆点职责时，允许 1 个元素突破预算（如满屏出血的 hero 入场），但其余元素必须让位、错峰——"全页活但不同时躁动"依然成立。

- **无障碍降级（按需处理）**
  - 默认场景（公众页面 / 平台发布 / 内容面向不确定受众）：尊重 `prefers-reduced-motion`，用户开启"减弱动态效果"时动效降为瞬时淡入/直接切换。
  - **已知受众 & 个人场景**：动效处理由观者明确偏好决定（如"取消无障碍"或"强化动效"）；通用制作前先问，不擅自按默认值兑现。
  - 关键信息（报错、状态）**不能只靠动效传达**——文字 / 颜色应能独立表达（这条不挑场景，永远生效）。

- **动画十二原则精要（取设计常用 6 条）**
  1. 缓入缓出（Ease in/out）：没有生命的动作是匀速直线。
  2. 预备动作（Anticipation）：起跳前先下蹲，用户才"预料得到"。
  3. 挤压拉伸（Squash & Stretch）：落地压扁、弹起拉长，传递质量感。
  4. 跟随与重叠（Follow through）：主体停了，附属物（尾巴 / 阴影）还惯性摆一下。
  5. 夸张（Exaggeration）：情绪要"过一点"才看得出。
  6. 节奏（Timing）：快慢对比制造重点，全程同速 = 没重点。

### 五、与上下层 / 同层衔接
- **← 来自第 1 层**：载体决定"动得起动不起"（印刷品全静态、视频才有无穷动画）；环境决定"动多猛"（移动观看要短亮）；客观约束给"性能与无障碍红线"，本模块必须守住。
- **→ 给第 3 层形式组织**：镜头运动、元素位移路径、时间轴上的构图"呼吸"，规格都来自本模块的时序与缓动；形式组织只管"空间关系怎么随时间变"，节奏归本模块。
- **→ 给第 4 层信息叙事**：动效的先后次序 = 叙事次序。先亮标题再亮正文、错误最后红闪，本身就是故事逻辑。
- **↔ 同层其他子位置**：文字的入场方式（淡入 / 上滑）、图片的过渡（推近 / 翻转）、颜色如何随动效呼应，统一由本模块调度，避免各物料"各自动"。

## 备注
承接第 3 层形式组织：镜头运动与"构图随时间的呼吸"在形式组织模块落地，本模块只负责"动效规格"（动什么、怎么动、多快）。两者配合 = 一段既好看又讲得清的动。若某层（如印刷海报）完全不能动，本模块整段标注"静态交付"，相应规格留空。

## 补充 · 每页独立持续视觉锚点（避免「只有第一页动」）

> 「同屏同时运动元素 ≤3–5」是**一屏**的预算；**多页场景下每页也要有自己的持续可见视觉锚点**，否则观者会觉得"特效只加了第一个主题面，没延伸到其他的"，整体沉浸感断裂。

### 判据两问（多页 / 多主题面的场景）
- **场景是否多页 / 多屏 / 多主题面？**（品牌汇报 / 多段叙事 / 多 Tab / 多章节）→ 是 → 给每页加独立持续视觉锚点
- **每页除入场 reveal 外，是否还有"自己点燃的小烟火"？** 没有 → 这是断点——除了入场那一下，那页就死气沉沉，只有"陪跑"的全局粒子在飘

### 每页独立视觉锚点的几种通用做法（按载体自选）
| 锚点类型 | 适用场景 | 实现要点 |
|---|---|---|
| **持续微动 SVG** | 抽象概念页（香氛、音乐、自由） | 同心圆呼吸 / 水滴涟漪 / 几何缓慢旋转——opacity + transform 即可，5–8s 一个周期 |
| **点缀几何** | 文字密度高的页（定义、结论、观点） | 一根细线 + 持续扫光（0–100% 上下扫一遍）给"有东西活着"的暗示 |
| **章节序号装置** | 多章节导航（章标 / 进度） | 序号旁加小图形（圆点 / 方块 / 装饰符号），hover 时有反馈 |
| **数据衍生元素** | 数据 / 指标页 | 不只展示静态数字，让图本身有微动（轴延伸动画 / 点缓慢出现） |
| **持续滚动动效** | 多页叙事 | scroll 时触发徽标 / 章节条 / 装饰元素微动，而非只有入场那一秒 |
| **每章节图腾** | 主题汇报 / 全景式文档 | 每章节配独立的小 SVG 图腾（呼应主题色或核心隐喻） |

### 全局与局部的预算区分（关键）
- **全局持续氛围**（如 fixed 全屏粒子 / 屏下背景纹理）= **一个就够了**——它陪跑所有页，不算"每页的锚点"
- **每页独立的持续可见元素** = **每页至少一个**（SVG / 微动 / 几何装置均可），不与全局冲突
- **入场 reveal** = **不属于"持续可见锚点"**——它只是入场那一下，不算"活着"

### 实现参考（v1 多页锚点简例）
```css
/* 背景页：右侧香氛扩散圈（4 圈同心圆，错峰呼吸） */
.bg-anchor{position:absolute;right:6vw;top:50%;transform:translateY(-50%);opacity:.7;pointer-events:none}
.bg-anchor .ring{transform-origin:center;animation:breath 5s ease-in-out infinite}
.bg-anchor .ring.r2{animation-delay:1.2s}.bg-anchor .ring.r3{animation-delay:2.4s}.bg-anchor .ring.r4{animation-delay:3.6s}
@keyframes breath{0%,100%{transform:scale(1);opacity:.7}50%{transform:scale(1.08);opacity:1}}

/* 核心发现页：右下水滴扩散（3 圈错峰 ripple） */
.core-anchor{position:absolute;right:7vw;bottom:18vh;opacity:.6;pointer-events:none}
.core-anchor .ripple{transform-origin:center;animation:ripple 4s ease-out infinite}
.core-anchor .ripple.r2{animation-delay:1.3s}.core-anchor .ripple.r3{animation-delay:2.6s}
@keyframes ripple{0%{transform:scale(.6);opacity:.9}100%{transform:scale(1.6);opacity:0}}

/* 结论页：左侧纵向细线 + 向下持续扫光 */
.conc-anchor{position:absolute;left:9vw;top:18vh;bottom:18vh;width:1px;background:var(--line);overflow:hidden}
.conc-anchor::after{content:"";position:absolute;left:-2px;width:5px;height:40px;background:linear-gradient(180deg,transparent,var(--ink),transparent);animation:sweep 4s ease infinite}
@keyframes sweep{0%{top:-40px}100%{top:100%}}
```

### 与原有"克制 / ≤3–5"规则的关系
- **同一屏同时运动 ≤3–5（默认预算）**→ 仍然成立，但它是**默认值、不是硬上限**
- **破格触发器**：画面有且仅有一个视觉焦点 / 元素承担 signature 记忆点时，允许 1 个元素突破预算（其余元素让位、错峰）
- **每页都活、各自的小烟火** → 同样必要（避免单调）
- 两者的合成：**全页活但不同时躁动**——每页有持续可见元素，但多个持续元素错峰（不同时到达动作峰值），观感是"活但不闹"

### 媒体查询降级
- ≤980px：缩尺寸至 160–200px，opacity 降为 .35
- ≤640px：可用 `display:none` 直接隐藏（移动端重心在文字，不靠装饰元素）
