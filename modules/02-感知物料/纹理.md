# 第2层·感知物料 / 子位置：纹理

> 本子位置是独立可编辑模块，可单独编写，不依赖其他子位置文件。

## 本子位置定位
- 层：第 2 层 · 感知物料
- 子位置：纹理
- 一句话说明：质感、材质感、噪点 / 颗粒 / 渐变、触感联想（给平面物料加上「表面语言」）
- **心智模型**：纹理是第 2 层的「表面语言」——它不增加信息，却决定画面「看上去 / 摸上去」的材质感与温度。一张图是光滑塑料还是粗糙纸张、一个字块是印在木头上还是浮在玻璃上，全靠纹理定调。它是隐形的一层，用好了画面立刻「长」出真实感，用过了则脏、乱、抢戏。

## 在工作流中的位置（顺序执行）
- 上一步输入：第 1 层的「载体」（屏幕显示 vs 印刷——印刷还能上专色 / 烫印 / 压凹等真实肌理）、「环境」（光线影响纹理可见度）、「客观约束」（商用模式才查纹理素材版权）
- 本步要做：让画面元素（图、字块、色块）的质感 / 材质与整体肌理一致，融入而不突兀；产出「纹理规格」（主纹理类型 / 强度 / 混用方式 / 材质融入点）
- 输出给：第 3 层「排版构图」（字块「长」进材质、纹理分区）、「空间」（纹理营造氛围与景深）；同层喂给「图片 / 颜色 / 模型」的表面质感

## 操作要点

### 1. 纹理家族分类（按材质来源选对表面）
| 类型 | 观感 | 典型用途 |
|---|---|---|
| 颗粒 / 噪点 | 胶片感、克制、有呼吸 | 夜空 / 氛围底、全图统一颗粒 |
| 纸张 / 纤维 | 文艺、手感、素雅 | 文创 / 手账 / 出版风 |
| 布料 / 织物 | 柔软、温暖、亲切 | 服饰 / 家居 / 暖调场景 |
| 金属 / 石材 | 冷硬、高级、坚固 | 科技 / 工业 / 奢华 |
| 光效 / 渐变 | 通透、轻盈、科技 | 背景过渡、发光元素 |
| 几何 / 图案 | 节奏、秩序、品牌感 | 底纹重复、辅助装饰 |
| 流体 / 笔触 | 自然、流动、手作 | 艺术 / 概念 / 手绘风 |
| 手绘肌理 | 个性、温度、非标准 | slogan / 强调元素 |

> 纹理要「服务内容」：文艺用纸纹、科技用金属光效、温暖用织物——错配会立刻出戏。

### 2. 四步定位法（确定纹理系统）
1. **定用途**：是全局氛围底（全图颗粒）？还是局部材质（字块压木纹）？还是点缀（笔触强调）？
2. **定类型**：上表选材质（颗粒 / 纸 / 布 / 金属 / 光效 / 几何 / 流体 / 手绘）。
3. **定强度**：透明度与混合模式（正片叠底 / 叠加 / 柔光），弱则隐、强则显——多数情况要克制。
4. **定混用**：单一主纹理统一全图，至多 +1 种对比纹理作强调，禁止多纹理打架。

### 3. 维度五件套（描述一套纹理的五个角度）
- **材质类型**：颗粒 / 纸 / 布 / 金属 / 光效 / 几何 / 流体 / 手绘
- **强度与透明**：叠加透明度、混合模式，决定「看得见 but 不抢戏」
- **尺度与频率**：大尺度粗肌理 vs 细密颗粒；重复频率影响节奏
- **光影呼应**：纹理是否带受光 / 阴影（如金属高光、纸张起伏），要和第 3 层光照一致
- **混用层级**：主纹理（全局）+ 强调纹理（局部），层级清晰不杂乱

### 4. 关键方法与注意
- **材质融入（核心）**：元素质感取自画面本身——字块压在木头 / 布料 / 金属上时，随材质产生起伏、受光与边缘破损，比纯色填充更「长」进画面；可用 **噪点 / 颗粒 / 渐变** 贴合画面颗粒度，让叠加层不显假。
  - 激活词参考：质感 / 材质融入 / 肌理 / 颗粒 / 噪点 / 「字像印在材质上」
- **强度克制**：纹理是配角，**多数场景透明度 10–30%** 足够；过强会脏、会抢信息、会降低可读性。先隐后显，宁弱勿强。
- **与图片 / 模型材质一致**：本模块的纹理若作用在图片上，要和图片自身材质同源（照片是胶片感就别叠矢量噪点）；若作用在 3D 模型表面，材质参数要和第 2 层「模型」子位置统一。
- **屏幕 vs 印刷**：屏幕显示用数字纹理（噪点 / 渐变 / 叠加）；印刷可上**真实肌理工艺**——专色、烫金 / 烫印、压凹 / 击凸、UV 局部光油，质感远超数字模拟（见第 1 层载体印刷参数）。
- **AI 生成纹理**：提示词锚定材质 + 光照 + 尺度；注意无缝平铺（tileable）用于背景重复。
- **可读性与无障碍**：纹理绝不可压在正文区域干扰阅读；色弱人群避免仅靠纹理区分信息（需配文字 / 形状）。
- **版权（呼应第 1 层红线双模式）**：轻量模式自用能用的纹理即可；商用模式走可商用素材（CC0 纹理站 / 自绘），不盗用材质图。

### 5. 上下层与同层衔接
- **← 第 1 层**：载体定「屏幕纹理 or 印刷肌理工艺」；环境定纹理可见度（强光下细颗粒看不见）；客观约束商用模式才查纹理素材授权。
- **→ 第 3 层**：纹理规格喂给「排版构图」（字块如何「长」进材质、纹理如何分区）、「空间」（纹理营造氛围与景深过渡）。
- **↔ 同层**：图片（纹理背景图归属图片、本模块管叠加质感）、颜色（纹理受光色）、模型（3D 表面材质）。

## 自检清单
- [ ] 纹理类型是否服务内容（文艺=纸纹 / 科技=金属光效 / 温暖=织物）？
- [ ] 强度是否克制（多数 10–30% 透明，不抢戏、不脏）？
- [ ] 元素质感是否「材质融入」画面（字块随材质起伏受光）？
- [ ] 主纹理是否统一、至多 +1 强调纹理，无打架？
- [ ] 屏幕 / 印刷工艺是否匹配载体（印刷可否上烫印 / 压凹）？
- [ ] 纹理是否未压正文、未干扰可读性？
- [ ] 商用模式：纹理素材版权是否清白？
- [ ] 输出规格（主纹理 / 强度 / 混用 / 材质融入点）是否能直接喂给第 3 层？

## 备注
- 「材质融入」的质感要求归本模块（材质取自画面、肌理贴合）；而把字块**排布到材质位置、定层级**归第 3 层「排版构图」——两层分工。
- 与「图片」边界：一整张纹理背景图算图片；本模块管的是「给已有元素叠加的表面质感」。
- 与「模型」边界：3D 表面 PBR 材质归模型；本模块管平面物料（图 / 字块 / 色块）的 2D 质感叠加。
