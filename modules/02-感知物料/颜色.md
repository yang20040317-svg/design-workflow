# 第2层·感知物料 / 子位置：颜色

> 本子位置是独立可编辑模块，可单独编写，不依赖其他子位置文件。

## 本子位置定位
- 层：第 2 层 · 感知物料
- 子位置：颜色
- 一句话说明：色板、主辅点缀、对比度、明暗、文化语义（建立画面颜色体系）
- **心智模型**：颜色是「情绪与识别的第一语言」——人眼对色彩最敏感，颜色先于文字传递情绪（暖=活力、冷=理性）与品牌识别。一套协调的色板让画面「是一体的」，一套翻车的色板让所有好构图功亏一篑。颜色定调，其余物料在色板内跳舞。

## 在工作流中的位置（顺序执行）
- 上一步输入：第 1 层的「载体」（屏幕 RGB / 印刷 CMYK）、「环境」（光线决定对比底线）、「客观约束」（商用模式才做 WCAG 合规认证）、以及第 2 层「图片」抽出的画面主色
- 本步要做：建立画面颜色体系——定主辅强调、控数量、保对比、避语义冲突；产出「颜色规格」（色板 / 主色 / 强调色 / 对比度底线 / 语义映射）
- 输出给：第 3 层「排版构图」（色块层级、字色、点缀面积）、「空间」（色块正负）；同层喂给「文字」（字色 / 反白块）、「图片」（图上叠色）、「纹理」（受光色）

## 操作要点

### 1. 颜色角色分类（先给每个颜色派活）
| 角色 | 作用 | 占比 |
|---|---|---|
| 主色 | 品牌 / 主题识别，定整体调性 | 最大面积 |
| 辅助色 | 支撑主色、丰富层次 | 中等 |
| 强调色（点缀） | 引导视线、标注关键 | 最小，≤10% 面积 |
| 中性色 | 背景 / 文字 / 分隔（黑白银灰） | 依需要 |
| 背景色 | 画面底色 / 负空间 | 大面积 |
| 语义色 | 成功 / 警告 / 错误（绿 / 黄 / 红） | 按需，勿滥用 |

> 没有「派活」的颜色就是噪音——每加一种色，先问它是哪类、占多少。

### 2. 四步定位法（建立色板）
1. **定取色来源**：优先**取色于画面**——从主体固有色、环境色、背景主色抽主色，画面才「是一体的」。
2. **定色系调性**：暖（活力 / 亲切）/ 冷（理性 / 专业）/ 中性（高级 / 克制）/ 高饱和（张扬）/ 低饱和（文艺）。呼应第 4 层表达意图。
3. **定角色分配**：主色 1 个 + 辅助 1–2 个 + 强调 1 个，主色 **≤ 3 个** 最稳。
4. **定对比与底线**：文字 vs 底色对比达标（见关键方法）；文化 / 语义色避禁忌。

### 3. 维度五件套（描述一套色板的五个角度）
- **色相基调**：暖 / 冷 / 中性，决定情绪主调
- **明度对比**：明暗落差——对比强=清晰有力，对比弱=柔和高级
- **饱和度**：高饱和张扬、低饱和文艺克制
- **配色数量**：主色 ≤ 3，总色板 5–7 色封顶（不含中性）
- **语义映射**：颜色是否携带正确文化 / 功能含义（如红=警示 / 绿=通行）

### 4. 关键方法与注意
- **取色于画面（核心）**：画面内元素（字块 / 色块 / 点缀）的颜色取自画面本身——主体固有色、环境色、背景主色。**同色系 / 邻近色最稳**，对比色只作点缀；判定标准：单独看是元素，整体看是画面的一部分。
  - 激活词参考：同色系 / 取色于画面 / 环境色 / 融入 / 「字和背景融为一体」「颜色协调」
- **撞色只作点缀**：涂鸦线条、小色块可用撞色活跃画面，但**撞色只作点缀、控制面积、不覆盖主体**；主色控制在 3 个以内，撞色面积越小画面越稳。
  - 激活词参考：撞色 / 色块 / 活泼 / 「彩色点缀」
- **配色方案速查**：单色（同色深浅，最稳）/ 邻近色（色环相邻，和谐）/ 互补色（对角，强对比醒目）/ 三角色（三均匀分布，活泼平衡）/ 分裂互补（互补的相邻，对比不刺眼）。大多数设计用邻近 + 1 强调色最安全。
- **对比度与可读性**：文字 / 关键信息 vs 底色要有足够对比（轻量模式也要保基本可读底线）；**商用模式才做 WCAG AA（正文 ≥ 4.5:1、大字 ≥ 3:1）合规认证**。弱光 / 户外环境调高对比。
- **色盲友好**：避免「仅靠红绿」传递信息（色弱人群分不清）；用形状 / 文字 / 明暗辅助区分；商用模式必查。
- **屏幕 vs 印刷**：屏幕用 RGB / HEX；印刷转 CMYK 并警惕「屏幕艳、印刷灰」的色差，关键色出数码打样。
- **文化 / 语义语义**：红色在中国 = 喜庆（非仅警示），西方红 = 危险；跨国项目先查目标文化忌讳色。

### 5. 上下层与同层衔接
- **← 第 1 层**：载体定 RGB / CMYK；环境定对比底线；客观约束商用模式才做 WCAG / 色盲合规。
- **→ 第 3 层**：色板喂给「排版构图」（色块层级、字色、点缀面积控制）、「空间」（色块正负空间）。
- **↔ 同层**：图片（从图抽主色）、文字（字色 / 反白块）、纹理（受光色）、模型（材质配色）。

## 自检清单
- [ ] 主色是否取色于画面（主体 / 环境 / 背景），整体「是一体的」？
- [ ] 主色是否 ≤ 3 个、撞色只作小面积点缀、不覆盖主体？
- [ ] 色系调性是否呼应第 4 层表达意图（暖 / 冷 / 中性）？
- [ ] 文字 / 关键信息对比是否达标（轻量保可读，商用做 WCAG）？
- [ ] 是否避免「仅靠红绿」传递信息（色盲友好）？
- [ ] 屏幕 RGB / 印刷 CMYK 是否选对、关键色有无色差风险？
- [ ] 文化 / 语义色是否避禁忌、含义正确？
- [ ] 输出规格（色板 / 主色 / 强调 / 对比底线）是否能直接喂给第 3 层？

## 备注
- 「取色、同色系、撞色点缀」的色板要求归本模块；把这些颜色**排进版面、定层级与面积**归第 3 层「排版构图」——两层分工。
- 颜色是第 5 层「主观输出」的物质触发器：冷调生冷静、暖调生活力、低饱和生高级——第 5 层要的「感觉」很大程度由本层预先决定。

## 补充 · 极窄色板 + 单点语义化强调色

> 完整方法见 `subskills/design-metaphor-narrative` 第五节（与「色彩作结构」对偶：加色构成法管**一张平面内的构成色彩**，本节管**一个站点/长页的全局色彩纪律**）。

- **四色就够**：背景（微暖白 / 近黑）+ 正文灰 + 弱化灰 + **一个**强调色。
- **强调色纪律**：全站 ≤2 处，每处都**承担语义**（进行中 / 可交互 / 关键节点）；先定义"这颜色代表什么状态"再决定用哪；其余一律灰阶靠明度差拉层级。
- **自检**：把强调色临时改成灰色，若画面崩了 → 颜色在承担结构职责（对）；若只是"没那么好看" → 强调色是装饰（删）。
