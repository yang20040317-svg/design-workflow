# 第2层·感知物料 / 子位置：图片

> 本子位置是独立可编辑模块，可单独编写，不依赖其他子位置文件。

## 本子位置定位
- 层：第 2 层 · 感知物料
- 子位置：图片
- 一句话说明：摄影 / 插画 / 图标 / 3D 渲染图 / 数据图 等一切位图与矢量图素材的风格、质量、裁切、版权
- **心智模型**：图片是第 2 层的「视觉基石」——它往往占据画面最大面积，直接决定氛围、真实感与信息可信度。文字再强，图不对也立不住。图片不是「配角」，是承载第一眼注意力的主物料之一。

## 在工作流中的位置（默认顺序 · 可跳层回补）
- 上一步输入：第 1 层的「载体」（画布尺寸 / 分辨率 / 格式色彩）、「环境」（观看光线决定对比底线）、「客观约束」（商用模式才查图片授权红线）
- 本步要做：选定画面素材类型与来源、定风格基调、控质量与裁切、清版权；产出「图片规格」（主图风格 / 质量 / 裁切比例 / 安全区 / 版权状态）
- 输出给：第 3 层「排版构图」（图片占多大、放哪、主体是否被裁）、「空间」（正负空间由图决定）；同层喂给「颜色」（取色于图）、「纹理」（表面质感）、「文字」（图文层级）

## 操作要点

### 1. 图片家族分类（按用途选对素材形态）
| 类型 | 典型用途 | 气质 | 来源倾向 |
|---|---|---|---|
| 纪实摄影 | 真实场景、产品、人物、活动 | 真实、可信、有温度 | 实拍 / 图库 / AI 写实 |
| 插画 | 品牌感、概念、氛围、无法实拍的 | 风格化、有设计味 | 手绘 / 数位板 / AI 插画 |
| 3D 渲染图 | 产品、空间、等距场景 | 干净、可控、质感强 | 见同层「模型」子位置 |
| 图标 / 图形 | 指示、功能、装饰符号 | 简洁、统一 | 矢量绘制 / 图标库 |
| 数据可视化图 | 图表、信息图、地图 | 理性、清晰 | 制图工具 / 代码 |
| 纹理 / 材质图 | 背景、表面质感 | 氛围、底纹 | 拍摄 / 生成 / 图库 |
| AI 生成图 | 概念稿、氛围、不易实拍的 | 灵活、快、可控风格 | 文生图工具 |

> 形态选错 = 气质不对。要「真实可信」用纪实摄影；要「品牌设计感」用插画；要「干净产品感」用 3D 渲染。

### 2. 四步定位法（确定要什么图）
1. **定用途**：是主视觉（占大面积）？还是辅助 / 背景 / 装饰（占小面积）？主视觉要求最高。
2. **定类型**：上表选形态（纪实 / 插画 / 3D / 图标 / 数据 / 纹理 / AI）。
3. **定来源与版权**：实拍自产 / 免费可商用图库（轻量模式即可）/ 商用授权图库（商用模式必查授权）/ AI 生成（注意平台版权条款）。
4. **定规格**：分辨率（印刷 300dpi、屏幕 72–150dpi）、裁切比例（匹配载体画布）、安全区（核心主体不进被裁区）。

### 3. 维度五件套（描述一张图的五个角度）
- **风格基调**：写实 / 扁平 / 手绘 / 胶片 / 极简 / 国潮 … 全项目统一一种主风格
- **质量与分辨率**：清晰度、噪点、是否够印刷 / 大屏；模糊或低清会直接拉垮质感
- **裁切与构图**：主体位置、留白、是否预留标题安全区；裁切服务构图不伤主体
- **色彩基调**：冷 / 暖 / 高饱和 / 低饱和，决定后续「颜色」子位置取色方向
- **版权与来源**：自产 / CC0 / 可商用授权 / 待授权，商用模式必须清白

### 4. 关键方法与注意
- **「纪实 × 手绘」对撞提生气**：实景照片作底、手绘 / 涂鸦 / 贴纸 / 插画元素作点缀，画面立刻活泼不单调。装饰素材要和底图同主题、同色系或刻意撞色，且**克制不压主体**（放次层）。该「照片作锚点 + 手绘扩展」范式源自拾景 zine 方法论（来源署名见 `references/来源署名/Zeejay0-gathered-scenes-zine.md`）。
  - 激活词参考：涂鸦 / 手绘 / 贴纸 / 插画风 / 文创 / 旅行手账 / 可爱风 / 手账风
- **来源与版权（呼应第 1 层红线双模式）**：
  - 轻量模式（个人 / 测试 / 自娱）：自己能用的图即可，不强制查授权。
  - 商用模式：走白名单（Unsplash / Pexels / Pixabay 标可商用、或已购授权）；AI 生成图确认平台允许商用；绝不盗用未授权图。
- **AI 生成图要点**：提示词锚定风格 + 构图 + 光照；出图后人工修瑕疵（手指 / 文字乱码）；注意平台对 AI 图的标注与版权条款。
- **裁切与安全区**：先按载体画布比例裁，核心主体放进安全区（如小红书 1080×1440 列表会裁上下、朋友圈 1:1 居中裁、抖音底部遮挡），标题压图处留干净底。
- **与文字 / 颜色混排**：图占主区时，文字放图留白或压暗角；取色从图里抽主色（见同层「颜色」）；图太花则文字加底块保对比（见同层「文字」）。
- **风格统一**：全项目多张图保持同一色调 / 颗粒 / 光影逻辑，避免拼贴感。

### 5. 上下层与同层衔接
- **← 第 1 层**：载体定分辨率与画布比例；环境定对比底线（户外强光的图要更高对比）；客观约束商用模式才查图片授权。
- **→ 第 3 层**：图片面积直接决定「空间」正负、喂给「排版构图」主体位置与裁切、喂给「镜头布局」景深与机位（若图本身带镜头语言）。
- **↔ 同层**：颜色（从图抽主色）、文字（图文层级）、纹理（表面质感延续）、模型（3D 渲染图即本类一种）。

## 补充 · 满铺图避让与截图美化

- **满铺图先测安静区（quiet zone）**：照片铺满画布时，先定位主体（人脸/产品/密集文字/高对比区）的「安静区」——文字避开这些区，只放在图的安静/低信息处。
- **局部 tint 而非全图遮罩**：文字必须压图时，优先**仅对文字区域加局部半透明 tint（压暗/压色）**，不默认给整图加遮罩（全图遮罩会压垮照片质感）。
- **截图/UI 展示用设备外框 + 材质背景**：展示 App 截图、界面时，套设备外框（手机/浏览器框）+ 材质背景提升质感与真实感；素材缺失时以实色块 fallback，不留空洞。

> 这些专项方法论的关键红线（已随内容抽离，但本文件保留最重要的判定原则供快速判断）：
> - **自动线稿提取仅简单背景有效**：拿到图先问"去色扔进边缘检测器，主体轮廓能压过背景纹理吗？"不能就走 mask/换图/人机协作。
> - **AI 生图不做真透明背景**：让模型生成纯色背景（绿/蓝），再用 `chroma_key.py` 抠图；白/浅色/与主体同色背景禁用。
> - **live photo 绘画红线**：补全/拟人化线条必须基于真实轮廓、整体衔接、统一曲线语言、不替用户加元素。

## 自检清单
- [ ] 是否明确了图片用途（主视觉 / 辅助 / 背景 / 装饰）？
- [ ] 是否选对了类型（纪实 / 插画 / 3D / 图标 / 数据 / 纹理 / AI）？
- [ ] 风格基调是否统一、符合第 4 层调性？
- [ ] 分辨率 / 裁切是否匹配载体画布与安全区？
- [ ] 装饰元素是否克制、不压主体（放次层）？
- [ ] 色彩基调是否给「颜色」子位置明确了取色方向？
- [ ] 商用模式：图片版权是否清白（白名单 / 已授权）？
- [ ] 输出规格（面积 / 位置 / 裁切 / 版权状态）是否能直接喂给第 3 层？

## 备注
- 「摄影 × 手绘对撞」的素材选择归本模块；而把这些装饰元素**放在次层、不抢标题**的排布归第 3 层「排版构图」——两层分工，不要越界。
- 图片与「模型」有重叠（3D 渲染图既是图也可来自模型子位置）：若产出的是可旋转 3D 资产走「模型」，若只是渲染出一张静帧图则归本模块。
