## 操作要点

### 第一性：信息字块「长」在画面里
- 字块与主体在视觉上**无法分离**——它属于这个画面，不是后期压上去的图层。
- 判定标准：遮住字块，画面失去一半以上的意义与气质；遮住主体，字块失去落脚点。二者互为依托，缺一不成立。

### 一、沿主体轮廓生长（弯曲 · 贴合 · 缠绕 · 穿插）
- 字块轮廓跟随主体外形：沿边缘弯曲、贴合表面弧度、缠绕结构、穿插空隙。
- 不做与主体轮廓平行错位或悬空漂移的「悬浮字」；先贴合，再谈层级。
- **场景匹配（激活词）**：影视片头 / 片名贴合物体 / 三维环绕字 / logo 弧形字 / 插画题字 / 「字绕物体」「字贴边缘」「路径文字」「缠绕字」

### 二、制造前后遮挡（空间关系）
- 字块被主体部分遮挡（如手指挡住部分笔画、前景物体掠过），产生明确的前后空间关系。
- 遮挡不是瑕疵，是「长在画面里」的最强证明。
- 注意：被遮挡处要有收笔逻辑，不能是整块平移被切。
- **场景匹配（激活词）**：实景合成 / 前景遮挡 / 手挡字 / 景深字 / 字在物体后面 / 「手指挡住」「穿过物体」「字被遮住」

### 三、投影服从真实光线
- 字块的投影落在主体或背景上，方向、长度、柔和度服从画面主光源。
- 光线逻辑成立，字块就「长」在地面、身上；不成立，字块就浮起来。
- **场景匹配（激活词）**：实景合字 / 落地字 / 环境投影 / 逆光字 / 户外广告 / 三维渲染 / 「投影跟随光源」「字有影子」「影子方向」

### 四、层级靠「重细对比」拉开
- 主标题用重字重/粗体，第一眼醒目；副标语与说明用纤细字体承接，自动退后。
- 层级不靠字号堆，靠「重 vs 细」的对比张力；字越细越轻、越靠后，信息主次一望即知。
- 大字手写主标题配实景底图时，手写质感弱化机械生硬感，标题「长」得自然。
- 字重 / 字库 / 行距的具体选择见 `02-感知物料/文字.md`。
- **场景匹配（激活词）**：海报 / 封面 / Banner / 杂志 / 主副标题 / 标题层级 / 粗体细体 / 「标题醒目」「字体对比」「大字配小字」

### 五、信息分区（分界线 · 线框 · 小色块）
- 用分界线、线框、小色块划分信息区域，扫一眼即知结构，无需思考。
- 分区元素本身也是装饰：线、框、色块的疏密与粗细参与画面节奏，同时承载「分类」功能。
- **场景匹配（激活词）**：海报分区 / 信息图表 / UI 界面 / 包装 / 线框 / 小色块 / 分隔线 / 模块化 / 「分类标签」「功能区划分」

### 六、英文小字补白（点缀字）
- 英文小字、细体点缀填充空白，让空处「有呼吸但不空荡」；点缀字只补白，不抢主体。
- 留白本身的节奏、呼吸感、间距控制见 `03-形式组织/空间.md`。
- **场景匹配（激活词）**：实景海报 / 摄影底图 / 文旅宣传 / 极简 / 英文字点缀 / 「干净」「简约」

### 七、装饰元素只放次层
- 涂鸦、撞色、手绘等装饰元素作为画面点缀，活泼不单调。
- 排版职责：装饰必须尺寸克制、放在次层，不得压过标题层级。
- 装饰素材的风格与选材见 `02-感知物料/图片.md`，撞色搭配见 `02-感知物料/颜色.md`。
- **场景匹配（激活词）**：涂鸦 / 撞色 / 手绘 / 贴纸 / 插画风 / 文创 / 旅行手账 / 「活泼」「可爱风」「手账风」

### 八、经典构图法则（版面骨架）
- 「字长进画面」之前，先定版面骨架。骨架决定稳不稳、焦点在哪：
  - **三分法**：横竖各分三等分，四条线交点放主体/主标题——最稳、最不易出错，通用首选。
  - **中心构图**：主体居中，庄重聚焦，适合 logo 感、仪式感、产品独秀。
  - **对称 / 非对称**：对称显秩序古典；非对称（重量偏移一侧）显动感现代，靠留白平衡另一侧。
  - **对角线 / 引导线**：用线条、轮廓、手势把视线引向主体，制造纵深与动势。
  - **框架式**：用前景框（门窗 / 树枝 / 色块边）把主体框住，聚焦且添层次。
  - **视觉重心**：人眼习惯先落左上、顺时针扫读，重要信息优先放视觉重心区（非几何正中）。
- 法则不是铁律——可"故意破格"制造张力，但先懂规矩再破，破得有理由。

### 九、栅格系统（对齐地基）
- 多元素排版靠隐藏栅格兜底，避免自由散落失序：
  - **栏栅格**：分 2 / 3 / 4 / 6 / 12 栏，元素跨栏对齐；**12 栏最灵活**，适合复杂版面。
  - **模块栅格**：固定模块尺寸拼贴（卡片化 UI、信息图、展板分区）。
  - **基线网格**：文字行基线对齐同一基线，纵向产生秩序感。
- **断网 / 破格**：偶尔让某元素跳出栅格（大图出血、标题跨栏、元素旋转），制造焦点；但多数元素仍守格才不显乱。栅格是"隐形的"，观者感觉不到但能感到"不乱"。

### 视觉流向（动线设计）
- 版面要预设视线动线：观者第一眼看哪、顺着什么路径读到哪、在哪停顿。
- 用「大小梯度 + 明暗对比 + 指向（眼神 / 手势 / 线条）+ 留白停顿」把视线按次序带走。
- **动线即叙事**：流向 = 故事讲的先后，与第 4 层「故事逻辑」强耦合——先被带到的，就是先讲给观者的。

## 补充 · 落位精度校准（数值不糊，才不落回平庸）

> 本模块前面讲的是**手法与骨架**（沿轮廓 / 遮挡 / 重细对比 / 构图画法 / 栅格）；但骨架对了、数值糊了，照样不好看。落位时对照 `references/审美精度标准.md` **B 段**的 8 条精度标准，其中最常翻车的三条：

- **大字号反向收紧字距**：≥48px → `-0.02 ~ -0.04em`；24–48px → `-0.01 ~ -0.02em`；≤16px → `0 ~ +0.01em`。**绝不给大标题加正字距**——这是最典型的"没做过排版"痕迹。
- **圆角 / 线宽 / 阴影同源**：整套设计圆角值 ≤2 种、线宽 ≤2 种、阴影同一光向且 ≤3 层。混用多个相近值（3px/5px/6px）= 拼贴感。
- **对齐挂网**：每个元素都要能指出"它对齐了谁"；≥80% 元素应对齐同一组基准线，找不到对齐依据的元素要么挂网要么删。

> 其余 5 条（字号阶梯比 1.2–3、行高反向补偿、灰度 ≥4 级、间距等比递增、放大 200% 近看有东西）见该文件 B 段。

## 补充 · 版式选型与密度规则

- **版式选型优先于自由发明**：动手前先从「预设版式骨架库」中选一个最贴近内容结构的骨架（叙事型：氛围/生活/故事流；结构型：数据/方法/对比/矩阵），再往里填文案，**不每次重新发明页面结构**。骨架库 = 上方八·经典构图法则 + 九·栅格系统的组合实例。
- **密度规则（横带法）**：把画布在垂直方向切成若干横带，每一带要么有实质内容、要么有「主动留白」的理由（如分隔/呼吸/视线停顿）；避免出现「既无内容又无理由」的空洞带。
- **画板尺寸适配**：同一内容要发多个平台时，按目标画板比例（常用 3:4 竖版 / 1:1 方版 / 21:9 宽版 / 16:9）做规格适配，主载体定稿、其余只做比例与裁切适配，不重画。

## 补充 · 排面（实验性 / 艺术类海报的文字空间排布）

> 来源：公众号「字有分寸」2026-08-31《中文排版没有设计感？我就是用这4招，来搞定！》。**模式 1（领域适配）的排版知识增量，非模式 2 品味**；仅当 brief 需要"实验性 / 张力 / 松弛感"时启用，常规编辑式排版仍走上方八·九的稳定骨架与栅格。字感（字体匹配主题气质）归 `02-感知物料/文字.md`。

- **排面 = 文字在画面中的"空间表现"**。以下 4 种手法都主动打破八·九的规整对齐 / 栅格，用于有张力需求的艺术海报：
  1. **横竖混排 + 多种对齐**：横排竖排交错、混用不同对齐方式，打破单一整齐，制造视觉节奏。
  2. **错位编排**：把字组拆成小组、位置上错位错动；错开处的留白让文字更有层次、活而不死板。
  3. **路径编排**：字沿形状 / 图片 / 线条轮廓排布，比前两种更灵活有趣、带视觉动态。
  4. **歪扭 + 堆放**：随性堆叠、显探索性，最考验排版力。
- **纪律**：实验排面 ≠ 乱排。须控制好信息组等级划分、疏密关系、大小对比，否则容易"排得乱七八糟"；先懂上方规矩，再为明确理由破格。

## 备注
核心：排版的第一性不是「摆字」，是「让字长进画面」。三种字块布局手法——沿轮廓、被遮挡、投影随光；三种组织手法——重细对比、线框分区、点缀补白。颜色/质感/留白/装饰素材等一律交给对应模块，本模块只做排版。判定标准：遮住它，画面就不成立。
