# 第3层·形式组织 / 子位置：空间

> 所属工作流步骤：第 3 步（顺序：第一层 → 第二层 → 第三层 → 第四层 → 第五层）
> 本子位置是独立可编辑模块，可单独编写，不依赖其他子位置文件。

## 本子位置定位
- 层：第 3 层 · 形式组织
- 子位置：空间
- **一句话说明**：留白、正负空间、层级间距、呼吸感——决定画面"松紧"与"气口"。
- 心智模型：**空间不是被填满后剩下的边角，而是主动的构图力量。** 留白给主体呼吸、给视线落点、给高级感；间距分级本身就在唱歌（疏密即节奏）。"空"不等于"无"，空处是观者眼睛休息和想象力进入的地方。

## 在工作流中的位置（顺序执行）
- 上一步输入：第 1 层「载体尺寸/环境观看距离」+ 第 2 层「图片/颜色/纹理」物料 + 本层「关系」的主次权重
- 本步要做：分配画面的留白与间距——留多少白、层级之间间隔几级、用不用网格、边界留多少气口，让主体有呼吸、画面不填满也不空荡
- 输出给：本层「排版构图」（落位时套用本步的间距阶梯与网格）、「镜头布局」（景深/画幅呼应空间感）；间接服务第 4 层（留白引导阅读节奏）

## 操作要点

### 1. 空间语言家族分类表
| 类型 | 含义 | 适用场景 |
|---|---|---|
| **留白** | 主体四周的空区域，主动留出的气口 | 极简/高级感/文旅实景/大标题海报 |
| **正负空间** | 主体（正）与空白（负）互为形状，负形也参与构图 | 创意 logo、双关图形、极简海报 |
| **层级间距** | 标题/正文/标注之间的间距分级 | 所有含文字层级的设计 |
| **网格系统** | 隐藏的栏/列/基线，元素对齐其上 | 信息密集、多元素排版 |
| **边界呼吸** | 元素不顶边、四周留安全气口 | 社交媒流体、印刷出血外 |
| **比例留白** | 留白占整体面积的比例（如 60% 空） | 极简风、画廊感 |

### 2. 具体怎么操作（四步定位法）
1. **定留白量**：根据第 1 层「环境/载体」与调性——高级极简留白 ≥50%，信息密集留白 ≤30%；文旅实景靠留白出质感，不堆特效。
2. **定层级间距**：建立 3–4 级间距阶梯（如 8/16/32/64px），标题组间距大、组内紧，疏密对比即节奏。
   - ⚠️ **用等比不用等差**：×1.5 或 ×2（硬朗 `4/8/16/32/64`；柔和 `4/8/12/20/32` 斐波那契）。等差（8/16/24/32）会产生"均匀即无层级"的平感——间距最常见的隐性失误。完整精度标准见 `references/审美精度标准.md` B 段。
3. **定网格**：多元素时拉隐藏网格（栏/基线），所有元素对齐交点，避免自由散落。
   - 验收：**每个元素都能指出"它对齐了谁"**，≥80% 元素挂在同一组基准线上；指出不来的 = 游离元素，挂网或删。
4. **定边界呼吸**：核心信息不顶边，四周留安全气口（呼应第 1 层载体安全区），防止裁切丢失。

### 3. 维度五件套
- **留白比例**：整体空白占画面面积（稀疏/适中/密集）
- **间距阶梯**：层级之间的间隔分级（几级、倍率关系）
- **网格系统**：是否用栏/列/基线网格、几栏
- **正负空间形状**：负形（留白区域）的轮廓是否呼应主体、是否成双关
- **边界呼吸**：元素距画布边缘的气口大小、是否顶边

### 4. 关键方法与注意
- **留白即高级感（核心）**：实景画面不依赖复杂特效——留白 + 层级就够出质感，复杂特效反而盖掉实景的真实感。空处「有呼吸但不空荡」。
  - **场景匹配（激活词）**：留白 / 呼吸感 / 极简 / 干净 / 简约 / 高级感 / 大量留白
- **呼吸不空荡**：留白不是偷懒，空的区域要有"为什么空"——引导视线、衬托主体、或负形参与构图；纯空一大片而无用意 = 空荡。
- **层级间距分级**：标题/正文/标注之间的间距分级，间距本身参与视觉节奏；疏密对比也是构图。
- **正负空间形状**：负空间（留白区域）的形状也在构图，注意留白区域与主体的轮廓呼应（如留白恰成月亮/水流的负形）。
- **网格兜底**：元素一多就散，拉隐藏网格让所有元素有对齐依据，自由中见秩序。
- **边界气口呼应载体**：四周留白量要和第 1 层「载体安全区」一致——信息流海报四周留够、印刷留出出血外的净空。
- **屏幕 vs 印刷**：屏幕可靠纯色留白；印刷留白靠纸张本色 + 专色/烫印留空，质感不同。
- **无障碍（仅商用）**：间距过窄会挤、过宽会散，保持可读的最小行距/段距；留白不牺牲信息可达性。

### 5. 上下层 / 同层衔接
- **← 第 1 层**：留白量受「载体尺寸」与「环境观看距离」约束（远看要更大留白/更高对比才不挤）。
- **← 第 2 层**：留白衬托「图片/颜色/纹理」；实景图靠留白出质感而非叠特效。
- **→ 本层 排版构图**：本步的间距阶梯与网格是排版构图的落位依据。
- **→ 本层 镜头布局**：景深虚化区域、画幅留白与空间感呼应。
- **→ 第 4 层**：留白节奏引导阅读次序（大留白=停顿，密排=连读）。
- **↔ 同层 关系**：留白本身是「关系」的一种（亲密性靠间距、对比靠疏密）。

## 自检清单
- [ ] 是否留出足够呼吸感、画面不过满？
- [ ] 留白是否有"用意"（引导/衬托/负形），而非纯空荡？
- [ ] 是否避免了与场景不搭的复杂特效（实景靠留白出质感）？
- [ ] 层级间距是否分级清晰（3–4 级阶梯）？
- [ ] 多元素时是否用了隐藏网格对齐？
- [ ] 负空间形状是否参与构图（呼应/双关）？
- [ ] 边界是否留了安全气口（不顶边、不裁切丢失）？
- [ ] 输出「空间规格」是否能被排版构图/镜头布局直接使用？

## 备注
- 空间 ≠ 排版构图：本模块定"松紧与气口"（留白量/间距阶梯/网格/边界），排版构图负责"字块怎么排、多大"（落位）。先有空间骨架，再谈落位。
- 文旅海报等实景画面「不用复杂特效、靠留白出质感」这一要求归本模块。
- 与「关系」强耦合：间距即亲密性、疏密即对比，两者共享间距语言。
