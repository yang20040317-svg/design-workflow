# 第3层·形式组织 / 子位置：镜头布局

> 所属工作流步骤：第 3 步（顺序：第一层 → 第二层 → 第三层 → 第四层 → 第五层）
> 本子位置是独立可编辑模块，可单独编写，不依赖其他子位置文件。

## 本子位置定位
- 层：第 3 层 · 形式组织
- 子位置：镜头布局
- **一句话说明**：镜头布局 = 相机怎么看这个画面——视角、景别、运镜、景深，决定观者"站在哪、看多远、被带去哪"。
- 心智模型：**画面不是被"画"出来的，是被"拍"出来的。** 即使静态海报不真有摄像机，也要用镜头语言去想——视角定姿态，景别定主次，运镜定节奏，景深定焦点。镜头一变，情绪全变（仰拍显崇高、俯拍显渺小、平拍显平等）。

## 在工作流中的位置（顺序执行）
- 上一步输入：第 1 层「载体/环境/客观约束」+ 第 2 层「图片/模型/动画」物料 + 本层「空间/关系」的布排
- 本步要做：为画面选定相机语言——站在哪（视角）、看多远（景别）、怎么动（运镜）、哪里实哪里虚（景深），把已经排好的元素"框"成一张有态度的画面
- 输出给：第 4 层（叙事次序 = 镜头次序）、第 5 层（镜头语言直接制造主观体验如崇高/亲密/疏离）

## 操作要点

### 1. 镜头语言家族分类表
| 维度 | 类型 | 适用场景 |
|---|---|---|
| **视角** | 平拍 / 俯拍 / 仰拍 / 鸟瞰 / 虫视 | 平拍=平等叙事；仰拍=崇高权威；俯拍=渺小全局；鸟瞰=上帝视角；虫视=压迫感 |
| **景别** | 远景 / 全景 / 中景 / 近景 / 特写 | 远景定氛围；全景交待环境；中景讲关系；近景见表情；特写抓细节情绪 |
| **运镜** | 固定 / 推 / 拉 / 摇 / 移 / 跟 / 升降 / 环绕 | 静态设计多用"虚拟运镜"——引导视线方向而非真动；视频/3D 才真动 |
| **景深** | 大景深（全清晰）/ 浅景深（焦点虚化）/ 选择性聚焦 | 浅景深把注意力钉死在主体；大景深让环境说话 |

### 2. 具体怎么操作（四步定位法）
1. **定视角**：根据第 1 层「客观约束/环境」与第 4 层想传递的态度选——要崇高用仰拍，要亲民用平拍，要宏观用鸟瞰。
2. **定景别**：根据第 4 层「信息优先级」选——主信息要大景别/特写突出，环境氛围用远景铺陈。
3. **定运镜（视线引导）**：静态设计用"虚拟运镜"——用构图线、明暗、指向把视线从 A 带到 B，对应第 4 层叙事流向。
4. **定景深**：根据主次——主体浅景深凸显，次要元素虚化；纯信息图可全清晰保可读。

### 3. 维度五件套
- **视角姿态**：平 / 俯 / 仰 / 鸟瞰 / 虫视（决定观者心理位置）
- **景别距离**：远 / 全 / 中 / 近 / 特（决定信息密度与亲密感）
- **运镜方向**：固定 / 推拉摇移跟（决定视线如何被带）
- **景深焦点**：全清晰 / 浅景深 / 选择性聚焦（决定注意力落点）
- **画幅与透视**：画幅比例（与载体呼应）、透视类型（一点/两点/三点/无透视扁平）

### 4. 关键方法与注意
- **视角即态度**：同一物体仰拍变英雄、俯拍变猎物——先想"我想让观者感到什么"再选视角，别随手平拍。
- **景别即主次**：主信息进近景/特写，环境进远景；别让所有元素都"中景"导致平均无力。
- **静态设计的"虚拟运镜"**：没有真摄像机，用 引导线（道路/手臂/光线方向）+ 明暗对比 + 大小梯度 把视线按叙事次序带走，这是把第 3 层"关系/排版"和第 4 层"故事逻辑"缝起来的针脚。
- **景深服务焦点**：浅景深只保主体清、背景虚，立刻制造"这就是重点"；信息过密时慎用虚化以免丢信息。
- **透视与画幅呼应载体**：一点透视显稳定庄重，三点透视显动感张力；竖版海报（如 1080×1440）天然适合中近景纵向构图。
- **和第 2 层「模型/图片」对齐**：若用 3D 模型或实景照片，镜头语言要一致——别主体用仰拍英雄感、背景照片却平拍纪实，会"穿帮"。
- **无障碍（仅商用）**：动态运镜若用于视频，注意 `prefers-reduced-motion`；静态设计无此虑。

### 5. 上下层 / 同层衔接
- **← 第 1 层**：视角/景别受「载体画幅」与「环境观看距离」约束（远看的海报要更大景别/更高对比）。
- **← 第 2 层**：镜头框住「图片/模型/动画」物料；3D 模型自带相机，镜头布局要与其一致。
- **→ 第 4 层**：镜头次序 = 叙事次序——视线被带到的先后就是故事讲的先后。
- **→ 第 5 层**：镜头语言直接制造体验（仰拍崇高、虫视压迫、浅景深亲密）。
- **↔ 同层**：承接「空间」（留白/区域）、「关系」（主次权重）、「排版构图」（落位）；镜头布局是它们三的"相机化收口"。

## 自检清单
- [ ] 视角是否与想传递的态度一致（仰/俯/平/鸟瞰）？
- [ ] 景别是否突出了第 4 层的主信息、弱化了次要？
- [ ] 静态设计是否有"虚拟运镜"把视线按叙事带走？
- [ ] 景深焦点是否把注意力钉在主体？
- [ ] 透视/画幅是否与载体（如竖版 3:4）匹配？
- [ ] 镜头语言是否与第 2 层图片/模型材质视角一致（不穿帮）？
- [ ] 输出「镜头规格」是否能被第 4/5 层直接使用？
- [ ] 多角度方案是否备了至少 1 个备选？

## 备注
- 镜头布局 ≠ 排版构图：排版构图管"元素放哪、多大"（落位），镜头布局管"相机怎么看"（姿态/景别/焦点）。先有镜头语言，再谈落位。
- 纯平面静态设计（无影像/3D）：镜头语言化为"虚拟运镜"与"视角暗示"，不真有摄像机；视频/3D/演示类才用真运镜与景深渲染。
- 与「模型」子位置强耦合：3D 模型的相机参数（焦距/角度/景深）就是镜头布局的落地值。
