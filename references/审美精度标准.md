# 审美精度标准（把"好看"落成数值与动作）

> **为什么有这份文件**：现有资产里，审美意图卡给**方向词**、惊艳手法库给**破格点**、反模板校准防 **AI 味**、技术校验防**硬伤**——但中间缺了一层：**"不出错"到"好看"之间的精度**。一个设计可以完全不 AI 味、毫无硬伤、方向也对，却依然平庸。平庸通常不是方向错，是**数值糊**。

**三段用法**：
- **A 段**：第 1 层填完审美意图卡后，把感觉词**翻译**成参数（动手前）
- **B 段**：第 2–3 层排版落位时，对照校准（做的时候）
- **C 段**：第 5 层验收，与技术校验清单**并列**跑（做完后）

---

## A. 感觉词 → 参数映射（翻译层）

> 审美意图卡要求"每个感觉词能落到具体手段"，但**没有给映射表**——结果就是填了"克制·精密·冷"，落出来还是默认参数。这一节补上翻译器。

**硬要求**：3 个感觉词，每个至少翻译成 **2 个可测参数**。只留形容词不算填完卡。

| 感觉词族 | 字号阶梯比 | 灰度层级 | 间距倍率 | 字重对比 | 细节密度 |
|---|---|---|---|---|---|
| **克制 / 精密 / 冷**（仪表盘感、Linear 类） | 1 : 1.5 : 2.25（温和） | 4–5 级，色相差 ≤10° | ×1.5 | 400 / 500（**不用 700**） | 低，靠 1px 线与字距出精度 |
| **高雅 / 编辑 / 杂志感** | 1 : 2 : 4（强对比） | 3–4 级，可含 1 个暖调 | ×2 | 400 / 700（或衬线 400/600） | 中，靠留白与栏宽出气质 |
| **戏剧 / 冲击 / 潮** | 1 : 2.5 : 6+（夸张） | 2–3 级，允许高饱和撞色 | ×2，留白极端（≥60%） | 500 / 800–900 | 高，可叠材质与错位 |
| **温暖 / 手作 / 人文** | 1 : 1.6 : 2.6 | 4 级，明度跨度小、饱和度中低 | ×1.6 | 400 / 600 | 中高，靠肌理与不规则 |
| **活泼 / playful** | 1 : 1.8 : 3.2 | 5+ 级，多色相 | ×1.5，但允许刻意打破 | 500 / 800 | 高，允许装饰 |

**参数之外的三问**（感觉词 → 手段的兜底，当表格没覆盖你的词时用）：
1. 这个词如果要**画出来**，画面上最密的区域在哪？（决定视觉重心）
2. 它的**反面**长什么样？（"精密"的反面是"粗糙"——那就去查 B 段哪几条没做到）
3. 观者要在**多远**感受到它？（远看靠大对比，近看靠细节密度）

**反向校验**：填完参数后盖住感觉词，只看这行参数自问——"能反推出那个感觉吗？"推不出 = 映射没做对，重填。

## B. 精度标准（最易翻车的 8 条）

> **不是原则，是数值**。原则技能里已经有了，这里只写"够"到底是多少，以及**最常暴露业余的那几条**。

1. **字号阶梯**：至少 3 级；相邻级比值 **≥1.2**（1.15 以下 = 层级糊成一团）、**≤3**（超过 = 断裂，不像一套）。常用 1.25 / 1.5 / 1.618 / 2。

2. **大字号必须反向收紧字距** ⚠️ **最容易暴露业余的一条**：
   - ≥48px → `letter-spacing: -0.02 ~ -0.04em`
   - 24–48px → `-0.01 ~ -0.02em`
   - ≤16px → `0` 或 `+0.01em`
   - **绝不给大标题加正字距**（这是最典型的"没做过排版"痕迹）。中文字号越大同理要收，但幅度减半。

3. **行高反向补偿**：Display 大字 `0.95–1.1`；正文 `1.5–1.7`；小字/说明 `1.4–1.5`（小字反而要稍紧，不是越松越好）。中文正文可在西文基础上 `+0.1`。

4. **灰度至少 4 级**：`主文字 / 次级 / 弱化 / 边线`。只做 2 级（纯黑 + 一个灰）必然显糙。弱化级与主文字的明度差 **≥30%**。

5. **间距等比递增，不要等差**：用 ×1.5 或 ×2，不要用 +8。等差（8/16/24/32）会产生"均匀即无层级"的平感。
   - 硬朗：`4 / 8 / 16 / 32 / 64`（×2）
   - 柔和：`4 / 8 / 12 / 20 / 32`（斐波那契）

6. **圆角 / 线宽 / 阴影同源**：整套设计里圆角值 **≤2 种**（如 `4px` 与 `999px`）、线宽 **≤2 种**、阴影 **同一光向 + ≤3 层**。混用多个相近值（`3px`/`5px`/`6px`）= 拼贴感，一眼散。

7. **对齐挂网**：每个元素都要能指出"它对齐了谁"。找不到对齐依据 = 游离元素，要么挂上网要么删。**≥80% 元素应对齐同一组基准线**。

8. **近看有东西**：完稿放大到 200% 看——有没有 1px 细线、字距补偿、微妙的明度分层？**"远看成立、近看空"是平庸的主因**。

## C. 三个物理验收动作（第 5 层必做）

> 技术校验清单查的是溢出 / 字号 / 碰撞——**全过了，东西依然可能难看**。这三个动作查的是"好不好看"，与技术校验**并列**跑，不是替代。

1. **缩略图测试**：缩到 **25%** 看。
   - 判据：还能不能立刻分辨出**主 / 次 / 辅**三级？
   - 分不出 = 层级对比不够 → 回去加大字号比或灰度差（B 段第 1、4 条）。

2. **眯眼测试**：眯眼看，或加 **8px 高斯模糊**。
   - 判据：画面应剩下 **3–5 个视觉重量块**。
   - 少于 3 = 空散（缺重心）；多于 6 = 碎、没有主次。

3. **倒转测试**：水平翻转（或倒过来）看。
   - 判据：**纯形式上的平衡是否还成立**？构图有没有偏向一侧？
   - 这一招绕过"读内容"的习惯，只看形状与重量分布——**最能查出"因为内容顺序对所以以为构图也对"的自欺**。

**三个动作全过，才算过了"好看"这一关**；之后再跑技术校验清单防硬伤。顺序不能反——先形式后硬伤，否则会陷入"一直在修溢出，从没看过整体"。

## 与既有资产的关系

| 既有资产 | 管什么 | 与本文件的分工 |
|---|---|---|
| `审美意图卡`（01-场景 小节 5） | 方向词（3 感觉词 + 对标 + 破格点） | **它给方向，本文件 A 段把词翻译成参数** |
| `惊艳手法库` | 破格记忆点（一轮最多 1 个） | **本文件管基础精度（不出错、够讲究），手法库管破格**。先过本文件，再考虑用手法 |
| `design-frontend` 反模板校准 | 防 AI 默认观感 | **反模板防"AI 味"，本文件防"平庸"**——不 AI 味但也不好看，同样失败 |
| `05-主观输出/感觉.md` 技术校验 | 防硬伤（溢出/字号/碰撞） | **并列关系**：先跑本文件 C 段看形式，再跑技术校验防硬伤 |

> 一句话：**方向由意图卡定，精度由本文件保，记忆点由手法库给，硬伤由技术校验兜。** 四者各管一段，缺任何一段都会产出"能看但不好看"的东西。
