- 图内**绝不**加任何原作者 `@署名` / 落款 / 公众号水印 / QR 码。
- 文档内来源标注（即本目录）可接受，但技能方法论正文保持匿名。
- 直接调用他人 **skill/runtime** 生成 → 遵守其 LICENSE 署名要求；仅借用**通用原理**并入自己的 skill → 产出无需图内署名。
