# huashu-icon-set（开源图标生图技能）

## 来源性质
GitHub 开源图标生图技能。提供图标生图血泪教训与批量生产脚本思路。

## 本次吸收的方法学（已通用化）
图标套系一致性 / 共享网格·线宽·圆角·视觉权重 / 多尺寸可读 / 具象名词 prompt / 背景色键控·品牌色避让·去溢色居中 / 网格批量 + 逐格兜底 + 风格锚点验证门控 / 对称翻转复用。可运行工具：`references/chroma_key.py`、`references/slice_grid.py`。

## 必须剔除的元素（红线）
- 原仓库名 / 作者署名
- 运行环境特定细节（豆包 image_gen / edit）
- 具体品牌、具体 hex 色值
- 图内 `@署名`

## 授权与署名边界
- 量化值标「示例值，非普适」。
- 图内不加 `@署名`；文档内来源标注（本文件）即可。
- 已通用化重写，仅留方法学。
