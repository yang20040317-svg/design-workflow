# lieflat-charts（开源图表方法论 / AI 可视化 skill）

## 来源性质
面向 AI Agent 的数据可视化 Skill，把数据变精致可交互 HTML 图表。核心价值是「数据→图型」选型与品味法典，非模板代码。

## 本次吸收的方法学（已通用化）
数据形状选图主键·非程序员说人话 Agent 翻译 / 一张图一个独立结论·图数由结论定·单页≤6 / 标题写结论不写图型名 / 细读型 vs 快读型两种阅读速度按场合选 / 视觉编码诚实性：柱不断轴·面积 sqrt·明度即数据 / 色彩语义：同交付单色系·类目>6 退灰阶·强调色唯一·去色仍可读 / 交互三问·库外新图现场造句抄形不抄魂·敢于说不 / 图表交付自检 13 项。

## 必须剔除的元素（红线）
- 图型编号 L1–G22
- moxt.ai 平台名
- PolyForm 许可文本
- 具体 hex 色值
- ECharts / Chart.js 引擎依赖
- 仓库名 / 作者署名

## 授权与署名边界
- 仅留方法学，剥离一切平台/许可/引擎特定细节。
- 图内不加 `@署名`；文档内来源标注（本文件）即可。
