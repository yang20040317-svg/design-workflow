## 需剔除 / 红线

> **校准说明（2026-08-29 修订）**：初版曾一刀切「禁复用其隐喻本身」，该条**过严，已撤回**。理由：旅行 / 航程 / 登机这类母题是设计界通用语汇（登机牌请柬、boarding pass 模板早已泛滥），属著作权不保护的「思想」层；真正受保护的是他**具体画出来的执行物**。故红线改为「禁具体执行物 + 整体近似度自检」，不再禁母题本身。

### 硬红线（禁）

- **禁复用美术资产**：`window-*.webp` / `cloud.png` / `boarding-pass*.png` / `folio/` 下全部 logo 与截图 / `case/` 下全部案例图与视频 / `memories/` 照片。
- **禁复用字体文件**：MB Sans / MB Mono / MB LCD（DS-Digital）为站点自有资源，不得提取、转存或嵌入产出。需同类效果时**自选可商用替代**。
- **禁复用文案**：站点原文（标语、导航词、案例正文）一律不抄。
- **禁复用代码**：不复制其 JS/CSS 实现。
- 图内**绝不**出现 `Mike Barton` / `mikes.cv` / 任何指向原站的署名、水印、QR 码。

### 自由层（可用）

- **通用母题与通用技法**：旅行 / 航程类隐喻、叠牌缩略、等宽体承载坐标与时间、单栏窄栏、渐进模糊底栏、gutter 章节标签等——属通用设计语汇，不受限。
- 本技能提炼的**方法学与参数区间**。

### 软红线：整体近似度自检（不一刀切，靠判据）

单个技法随便用；但**多元素叠加后整体观感与其作品高度接近**时应主动改向。判据（命中 ≥3 条即告警，须告知用户并调整）：

- [ ] 同为暖白底 + 单栏窄栏（≤600px）+ 左侧固定等宽信息轨
- [ ] 同样用「航段代码 → 年份大字 → 机构 logo → 叠牌案例」的四段式时间轴
- [ ] 同样以数码管 / 等宽大写数字作年份读数
- [ ] 同样以「门禁（刷卡 / 扫描）→ 内容」作为首访动线
- [ ] 同样以私人拍立得 + 情绪化 alt 收尾

> 命中告警**不等于禁止**，而是要求：换掉其中至少 2 个元素的**具体执行**（如数码管→衬线数字、叠牌→并排缩略、门禁→直接入场），把整体观感拉开距离。

## 使用边界

- 仅借用通用原理并入本技能 → 产出无需图内署名（沿用目录通用红线）。
